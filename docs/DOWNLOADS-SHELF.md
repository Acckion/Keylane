# 下载、截图管理与暂存架

## 本轮范围

新增内置「下载」扩展，在 Launcher 中搜索、预览、打开和管理一个获授权的下载目录。它管理本机文件，不读取浏览器历史、不控制网络下载任务，不提供暂停或续传。

截图联动直接复用 ScreenshotLibrary 的范围、扫描结果与 FolderChangeWatcher。没有第二套截图文件夹配置或监听，也不改变原有截图命令的剪贴板行为。

## 使用

- 设置 → 下载：通过右上角开关启用，选择并授权文件夹后才读取文件。可重新选择目录。
- 搜索「下载」进入 Launcher，支持名称搜索、预览、打开、复制文件、复制路径、Finder 定位和确认后移到废纸篓。
- 下载和截图管理操作菜单提供「加入暂存架」（⌘⇧S），使用暂存架既有的新建/复用行为、书签授权和去重。整条路径不替换用户剪贴板。
- 下载设置的「新下载自动加入暂存架」默认关闭。
- 截图管理设置的「新截图自动加入暂存架」默认关闭；使用现有搜索范围，仅识别系统截图/录屏，不将“包含所有媒体”中的普通图片自动入架。
- 自动功能启用或目录配置改变时，先建立现有文件基线，不把旧文件批量弹出。已有截图仍可手动加入。
- 自动联动要求暂存架扩展已启用，不绕过启用开关；失败在对应设置/页面反馈，源文件保留。

## 文件监听

下载只扫描目录第一层；不递归计算文件夹大小。隐藏文件、符号链接、常见临时下载后缀（`.crdownload`、`.download`、`.part` 等）不列入。文件夹可浏览和手动暂存，自动暂存仅处理普通文件。

新路径的大小、修改时间至少稳定两秒，并在后续复查中一致，才自动交付。复查仅在有待稳定文件时运行；正常空闲使用 FSEvents。该判断是文件系统启发式，不能保证识别任意下载器的真实完成状态；直接使用正式文件名、长时间暂停写入的程序仍可能被提前识别。

截图页关闭后，仅在自动联动开启且截图管理有访问权限时保留原监听；不额外启动 OCR。停用扩展会撤销待处理任务并释放监听与权限。关闭、重启或重新开启时重新建立基线，不补发离线期间的旧文件。

## 验证

- 文件跟踪器：基线、重复事件、持续写入、消失的待处理文件、临时文件与符号链接过滤。
- 原生下载控制器夹具：真实临时目录和 FSEvents；默认关闭、手动入架回调、搜索失效选择清除、临时后缀改名、稳定后一次交付及停用。
- 截图管理：现有完整回归；新集成覆盖同一监听后台交付、普通图片排除、重复事件、停用。夹具使用临时文件、独立偏好域和入架回调，不把它描述为真实浏览器端到端下载测试。
- 相关 Swift、脚本测试及签名安装包检查以交付记录为准；浏览器、真实权限弹窗和安装版实际入架仍需单独验收。

## Keylane 融合方向

本轮以共享文件动作将下载、截图管理与暂存架接通。后续扩展暂存架操作时，优先复用 Launcher 的文件动作、AI 附件、脚本与快捷指令入口，由同一套选择内容和授权贯穿流程；不另造 Dropover 风格的即时操作面板。本轮未增加这些后续能力。

### PR #206 两项 P2 修复

- 截图扫描同时核对配置范围与实际扫描范围；有范围暂时不可访问或枚举不完整时，不用截断的结果更新新文件基线。保守地延后该次自动交付，保留此前已见文件；范围恢复后旧截图不重复进入暂存架。
- 下载页分别保存操作错误和扫描错误。扫描成功只清除扫描错误，用户可从标准操作菜单显式关闭操作错误提示；无关成功操作不会隐式关闭提示。
- 合成回归分别覆盖“两范围中的一个暂时移走并恢复，旧文件不重新交付、新文件仍正常交付”和“入架失败后成功扫描，提示仍存在，随后显式关闭”。未读取真实下载或截图范围。
