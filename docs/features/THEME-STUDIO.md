# Theme Studio

需求来源：[issue #196](https://github.com/Acckion/Keylane/issues/196)。参考公开的 [Raycast Themes 手册](https://manual.raycast.com/themes) 中的主题编辑工作流；配色、实现和示例图形由 Keylane 提供。

## 使用

- 在 Launcher 搜索 **Theme Studio**，或在设置 → 通用 → 主题中打开工作室。
- 三栏分别为主题库、实时预览、颜色编辑器。内置主题只读，可复制后编辑。库中可以筛选深色／浅色。
- 支持纯色或双色渐变背景、角度、文字、选中项、加载指示器，以及七种辅助颜色。原生色块打开系统颜色面板，支持透明度和精确颜色输入。预览是一张按真实 Launcher 尺寸整体缩放的交互画面：输入搜索文字不改变固定示例列表，可向下滚动查看两行颜色与标签示例、五张原创灰阶网格卡片、四项表单及 Markdown／语法配色代码块。表单包括下拉选择、单行输入、多行输入和按钮，输入与选择在滚动后保留。搜索栏和底部操作固定在预览边缘，滚动复用 Launcher 的边缘渐隐。列表、底栏按钮、键帽、悬停玻璃和操作菜单复用 Launcher 的生产组件；支持选中、上下键、回车、⌘K、左右菜单、菜单搜索、子菜单与预览内的收藏和动作反馈。所有示例动作仅影响预览状态。
- 保存写入主题库；应用主题同时指定对应的深色／浅色主题并切换显示模式。右键“设为深色／浅色主题”只指定该模式的主题，不修改显示模式。在设置中选择“跟随系统”可自动切换两个主题。
- 编辑时切换条目或关闭工作室，草稿仍保留在本次应用进程中；退出应用前需要保存。还原只丢弃当前条目的草稿。编辑支持撤销。
- **切换主题** 命令在 Launcher 中提供主题列表与预览，回车应用。
- JSON 文件、复制 JSON、分享链接和剪贴板粘贴均通过明确的用户操作执行。打开分享链接会打开工作室并导入草稿，绝不自动应用。

窗口采用 SwiftUI `NavigationSplitView` 与 `inspector`；栏宽、侧栏／检查器显隐及工具栏由系统管理，通过 `NSHostingController.sceneBridgingOptions` 接入现有 AppKit 窗口。

## 格式与边界

这是 **Keylane 自己的主题格式**，并非 Raycast JSON 格式兼容实现。没有复制其他应用的内置主题或图片，不下载远程主题或执行导入内容。

文件为 `{"schemaVersion":1,"theme":{...}}`，主题包括 UUID、名称、`light`／`dark` 外观、背景和具名颜色。链接为 `keylane://theme?data=<base64 JSON>`。导入时总是生成新 UUID，因此不能覆盖既有主题。单文件最大 64 KB，最多保存 100 个自定义主题。字段值、名称、颜色集合、渐变角度和链接结构均验证。

主题库独立保存到 `themes.library.v1`。原有 `appearance`（跟随系统／深色／浅色）设置不变。损坏的主题库不会被静默覆盖；导出和重新导入主题使用 Theme Studio 的独立入口。旧的设置摘要导出不包含主题库。

主题作用于 Launcher（含紧凑模式及其中的列表、菜单和加载指示器）与 Theme Studio 中间预览。设置窗口使用系统文字、强调色和背景，不随 Launcher 主题改变；仍遵循原有深色／浅色外观设置。原生系统弹窗、应用／文件原始图标、媒体预览和网页内容保留自己的颜色；未逐个替换所有历史功能中显式指定的语义颜色。默认 Keylane 深／浅色主题保留原有系统玻璃效果。

## 验证

- `ThemeTests`：颜色解析、主题与主题库约束、深浅色分配、删除回退、导入不覆盖、JSON／链接往返和畸形输入。
- Debug 程序的 `--verify-theme-ui`：隔离偏好域，验证编辑／保存／应用边界、切换草稿、撤销、重新载入与损坏数据保留，渲染深浅色工作室与生产共用组件。不会启动真实 Model 或读取用户内容。
- 自动化渲染和本地打包不等同于安装版的用户验收；本轮未替换用户的已安装应用。

本轮验证：KeylaneCore 的 326 项测试、ProviderConfig 的 3 项测试及 27 项发布脚本测试通过；隔离偏好域集成验证通过，并在本机打开、截取和检查深浅色原生 Theme Studio 窗口。未执行安装版用户验收。

共用组件回归：紧凑 Launcher 的 9 个中心／边缘点击、文件 AI 现有回归通过。Release 构建、Apple Development 签名测试包及 DMG 挂载完整性／签名检查通过。

原生分栏复验：工作室使用 SwiftUI 提供的两条工具栏跟踪分隔线，自动检查两条 `NSTrackingSeparatorToolbarItem` 均存在；本机深浅色窗口截图已核对。

交互预览复验：通过原生鼠标事件点击左右底栏和主操作，通过原生文本编辑器输入、方向键与 ⌘K 验证固定结果和键盘操作；菜单搜索、子菜单、禁用项及仅预览内的收藏／反馈均通过，并检查深浅色与两侧菜单的实际窗口截图。共用菜单仍由原 Launcher 宿主校验命令上下文和执行权限。
