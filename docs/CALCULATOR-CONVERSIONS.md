# 计算器换算

在启动器输入 `5 km to mi`、`30 摄氏度转华氏度` 或 `100 美元转人民币`。单位换算支持长度、面积、质量、体积、温度、时间和速度。选中结果后按回车复制数值和目标单位。

汇率使用[欧洲央行欧元参考汇率](https://www.ecb.europa.eu/stats/policy_and_exchange_rates/euro_reference_exchange_rates/html/index.en.html)，通过欧元计算交叉汇率。结果显示欧洲央行提供的数据日期。ECB 通常在工作日更新，这是参考汇率。输入金额和币种在本机计算，网络请求只获取完整的公开汇率表。

最近成功读取的数据保存在本机。离线或更新失败时可使用缓存，结果会显示状态及数据日期。以法兰克福日期计算，数据超过三个自然日会标记过期。没有缓存时会显示原因。部分货币不在 ECB 发布范围内。
