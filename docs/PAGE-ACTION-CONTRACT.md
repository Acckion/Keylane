# 页面动作契约（第二批）

对应 BASE-03、BASE-11。基线 origin/dev 1eea4a6；本分支不包含搜索性能 PR #218。

## 统一动作来源

页面贡献 ActionSnapshot，一次派生主动作与菜单动作；同 ID 的菜单项使用主动作定义。底栏、回车和菜单快捷键读取当前贡献，不跨页面访问保存快照。文件页面通过 selectionActions 接收宿主当前筛选列表的选中 Entry，避免再维护一份模块选择；footerTitle 保留原来的底栏文字，不改变菜单标题。

LauncherAction.invoke 在执行前核对 enabled。宿主原有页面访问、模块 activation、选中项上下文与输入法保护继续生效；快捷键与菜单点击在执行前按当前 ID 重新解析，避免选择未变但可用性已变时执行旧处理器。替代 Return 不再携带执行闭包，只贡献动作 ID；菜单动作不可用或已经消失时，替代 Return 也不能执行。旧页面 submit 等字段保留为兼容适配，后续模块可逐步迁移，不再为新页面扩展独立分派。

样板：词典列表与详情、文件列表、Emoji 网格、脚本创建、快捷链接编辑和参数表单。Emoji 点击与键盘共用动作；快捷链接表单内部提交与底栏共用工厂。保持 UI、导航、Esc、中文输入、主次键位和数据格式。所有现存替代 Return 声明（剪贴板、文字片段、Emoji、Quick AI）均改为动作 ID 引用。

## 页面会话作用域

LauncherPageSession 属于一次页面访问，不属于模块后台服务。宿主负责建立和结束，统一持有旧 leave/releasePreview 回调与模块 startSession 清理。重复离页、模块撤销和重入清理不会再次释放。同页保留状态的隐藏/恢复复用原会话；真正离页或 activation 变更结束旧会话。

作用域允许登记清理和持有 Task，结束时取消工作并按逆序释放；异步回调通过 publish 检查访问是否仍有效。该接口由 UI 线程使用，不能替代业务控制器自己的查询代次检查。文件取消与预览、Emoji 查询停止已接入；其他页面既有 leave 回调自动归入作用域。剪贴板采集、索引和菜单栏服务保持原有独立模块生命周期。

## 验证与边界

模块注册集成覆盖：主动作/菜单同 ID、禁用执行拒绝、实时状态重建、替代 Return 缺失/禁用动作、会话任务取消、重复/重入/迟到清理、旧会话发布拒绝。完整应用构建覆盖实际模块接入；文件与 Emoji 用现有隔离脚本回归。

本批完成上述公共契约与样板迁移，不表示所有内置页面的兼容字段已经删除。完整动态目录、第三方 UI schema 和 AI 工具审批分别属于后续批次。

安装版 Esc、输入法、Quick Look、真实分享/粘贴及视觉一致性仍需实机验收；自动化与编译结果不替代该验收。本轮未安装、发布或自动合并。

验证结果：完整应用最终构建通过（14.51 秒增量）；模块注册/动作/会话集成、Emoji 和文件控制器隔离回归通过。Emoji 宏编译与文件类型元数据测试首次在受限沙箱下失败，允许系统工具访问后通过；测试使用临时文件、合成数据与测试剪贴板，不读取真实历史。未将这些结果标为安装版实机验收。
