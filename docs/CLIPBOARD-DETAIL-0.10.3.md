# 剪贴板详情布局 0.10.3

> 历史记录，描述该开发版的实现与当时的验证结果。

之前只复用了ResultDetailLayout左右分栏，右侧预览和信息仍为独立实现，未达到共用详情的目标。

## 当前结构

- ResultDetailLayout继续控制两列宽度；新增ResultDetailPane统一详情滚动、220pt上方预览、间距与内容边距。
- DetailInformationSection统一标题、交替行背景、标签和值的对齐及路径中间截断；来源可带系统应用图标。
- ResultFilePreview统一嵌入Quick Look及文件失效反馈；文件搜索和剪贴板单文件共同使用。多文件采用系统文档图标叠放并显示数量。
- FilePreviewMetadata共用异步文件属性读取。ClipboardDetail只提供四类内容、元数据和可展开的OCR/附加文字。
- 文字显示字符数和按系统分词的词数；图片读取原始尺寸与实际图片字节数；单文件显示路径及文件大小，多文件显示数量。采集格式和内部存储大小不混入主要信息行。
- 原复制/粘贴/置顶/删除与OCR入口继续在底栏及动作菜单，不在详情中重复一排按钮。
- 书签解析期间持有只读安全作用域，切换或退出详情后释放。未改变采集、数据库或原文件处理规则。

## 验证与边界

32项核心测试通过；独立命名剪贴板的文字/图片自动采集、富文本、多项目、OCR及原文件保护验证通过。版本和分发检查通过，发行脚本的6项测试通过；完整安装版人工交互仍待用户验收。

使用生成资料渲染文字、图片、单文件、多文件，在深色与浅色检查分栏、上方预览、下方信息及文字对比度。原生Quick Look在生成的文件上真实加载；未读取用户历史用于验收。这是组件渲染证据，不是完整安装版截图，不能声称1:1视觉验收通过。
