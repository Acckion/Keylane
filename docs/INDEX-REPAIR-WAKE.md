# 增量索引修复唤醒与规则复用

FILE-01 / BASE-11，PR #247，2026-11-25。

实机 c75bf63 进程曾在规则文件的 fstatat 中等待。随后完成恢复并持久保留 778 个失败路径。校准过的 60 个样本拆分相邻的同状态点，连续后台区间合计 41.28 秒，平均 CPU 4.97%，读取 1.31 MB，写入 9.68 MB。前台与切换区间单列，不用于比较后台。此轮包含自然文件事件，并非隔离基准。

- 普通父目录变更不再把待修复后代全部排入增量索引；直接改变待修复项、目录权限或所有者变化、创建／重命名和缺失事件仍触发应有的修复。启动重试和真正事件丢失的完整恢复不变。浅扫描不能丢弃后代的待修复记录。
- 增量批次内复用相同目录的忽略规则快照，包括空结果。快照最多 256 个目录，另有 1 MiB 的估算预算，下一批重新读取，不跨批缓存。清理保留记录时查找祖先只操作字符串，不再构建可能触发文件系统查询的 URL。
- 增量批次的规则读取次数仅以数值记录，不记录目录名或规则内容。

范围测试核对同批祖先规则读取次数、真实规则变更和丢事件路径。重启测试覆盖正常祖先通知不重试不可读子树，以及真实权限恢复保留正常修复。没有改变数据库版本或用户设置。单个底层 I/O 操作仍可能阻塞，不能把本轮减少重复查询等同于慢卷隔离；安装版长期能耗和内存目标须独立复验。
