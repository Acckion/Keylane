# AI 资源引用、固定快照与重新读取

## 三个不同的对象

- `AIResourceReference` 是模块命名空间内的稳定资源身份。URI 使用版本号、模块编码与来源 ID 摘要，不包含原始文件路径/数据库 ID。相同来源的内容变化不改变身份；不同模块相互隔离。URI 可编码、比较和持久化，但没有解析器或权限恢复入口。
- `AIResourceSnapshot` 描述一次不可变提取：资源引用、来源版本、正文摘要、读取时间和独立快照 ID。模块动作、聊天附件和工具读取结果复用它。正文仍保存在已有上下文/附件/结果字段，不重复存储。
- `AIResourceReader` 是仅驻留内存的模块来源解析器。它复用 `AIActionSource`，读取前后检查可用性、来源版本及取消。注册表原有激活/功能代次包装继续生效。已保存的 URI/快照不能重建 reader。

## 已确认的用户行为

加入草稿后固定当时的内容。源文件或模块记录随后变化，不自动替换，也不在发送时重新读取。用户点击附件上的“重新读取”才重新检查来源并生成新快照；保留附件位置/ID、原草稿和选区，不自动发送。失败、撤权、来源身份切换或超限时保留原快照，并显示错误。

重新读取仅支持当前草稿中仍持有运行期 reader 的来源。移除附件、取消读取、切换草稿或清空会使旧结果失效；刷新结果不能重新插入已删除附件。进程内保留草稿可保留 guarded reader；历史/导出/同步只保留快照元数据和正文，恢复后需重新选择来源，不能凭 URI 恢复权限。已发送消息保持不变。

原来的普通附件和旧聊天 JSON 不需要迁移，缺少资源元数据仍可展示和发送。OCR 图片附件、AI 生成结果等没有可验证 reader 的历史内容保持静态，不能用“重新读取”伪造权限。模块来源（含截图 OCR）和所选文本/PDF 文件使用公共 reader。

## 模块和工具边界

模块动作的预览/执行仍沿用原有发送前版本检查；快照身份不替代命令准入。日历来源按原事件 ID 读取最新已加载记录；截图按同一来源读取并核对版本；文件选择的组合身份按规范化 URL 序列生成，不能把所有选择都标成 `selected-files`。

工具的搜索引用、路径授权和分页游标仍是三套原有授权协议，不统一成跨运行 URI 权限：

- `keylane_read_clipboard`、`keylane_read_searched_file` 仍只接受当前运行内搜索返回的随机引用；文件引用仍有五分钟期限与原版本检查。文件改变后须重新搜索再确认，不自动跟随新版本。
- `keylane_read_file` 保留匹配目录和目标准备、逐次审批，`keylane_read_result` 保留原版本/私有结果快照与逐页审批，不重新扫描，也不变成“读取最新”。
- 原生文件读取及引用读取结果携带同一种宿主快照元数据。传输只发送原有 `text`，不把资源 URI/元数据转成模型可用权限；未改工具名称、参数、限额或确认循环。

目录枚举不读取正文，不生成快照，不申请权限。读取、重新读取与 OCR 均由显式选择触发。

## 验证边界

使用自建临时文件、命名测试剪贴板及模拟传输验证：稳定/隔离身份、非规范 URI 拒绝、旧编码兼容、正文摘要匹配、固定快照、显式刷新、错误回滚、来源切换拒绝、移除/重置竞态、运行期草稿恢复与历史不恢复权限。复验模块目录撤销、路径/引用/分页隔离、传输不泄漏宿主 URI。
