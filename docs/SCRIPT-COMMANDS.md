# 脚本命令

1. 从主搜索打开「管理脚本命令」，添加本机脚本文件夹。Keylane 扫描文件夹和子文件夹。可刷新目录，为每个脚本设置搜索别名、热键和启用状态。
2. 在主搜索选中脚本，或按它的热键，打开运行页。可填写参数、工作目录和超时。默认工作目录为脚本所在文件夹，默认超时为 30 秒。
3. 按「运行脚本」执行。运行页显示标准输出、错误输出和退出状态。运行中可取消，完成后可从操作菜单复制输出。

支持 Shell（`.sh`、`.bash`、`.zsh`）、Python（`.py`）、JavaScript（`.js`、`.mjs`、`.cjs`），以及带 shebang 的无扩展名可执行脚本。已设为可执行且带 shebang 的脚本使用声明的解释器。其余脚本按扩展名选用解释器，Python 与 JavaScript 依赖本机的 `python3` 和 `node`。

参数支持引号和反斜杠转义，直接作为进程参数传入。输出在当前运行页保留，最多 256 KB。脚本以当前用户权限运行，适合添加自己信任的脚本目录。

## 设置和内置命令

设置页顶部的开关控制脚本命令模块。「脚本文件夹」配置扫描范围。「命令」分组可分别设置以下入口的别名、热键与启用状态。

- **创建脚本命令**：选择保存位置并按扩展名生成模板。新位置会加入搜索范围，保存后在访达显示文件。已有文件保留。
- **重新加载脚本命令**：立即重扫已添加的文件夹，并显示发现数量。
- **搜索脚本命令**：打开独立脚本列表，支持按名称和别名过滤。打开结果后进入运行页。

「脚本命令」分组提供创建入口，以及已发现脚本的独立配置。

## 验证

- 自动化测试覆盖扫描期间不执行、跳过符号链接、中文与含空格的参数、工作目录、退出码、标准错误、超时、取消和输出上限。临时脚本验证取消与超时会停止同进程组的子进程。
- 在 macOS 上运行了生成的 Shell、Python 和 Node 脚本。测试使用临时目录和生成的数据。
- 使用隔离数据验证实际模块登记、主搜索别名、打开运行页、显式执行、输出和停用。安装版的实体热键与完整键盘路径待验收。
