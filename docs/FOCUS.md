# Keylane Focus

以 [Raycast Focus Manual](https://manual.raycast.com/focus) 及本轮提供的分类、会话、菜单栏和通知截图为交互参考，沿用 Keylane 的 Launcher、设置、列表、可搜索菜单和菜单栏登记组件。使用系统符号与应用自身图标，不包含 Raycast 的私有代码或品牌素材。

## 入口与行为

- 主搜索命令：开始、切换、完成、暂停、恢复、编辑专注；创建、搜索、导入专注分类。均可使用现有命令设置配置启用状态、别名和快捷键。
- 开始表单：目标、时长、屏蔽／允许模式，以及应用、网站和分类。支持不限时、预设、`45 min`、`1:30`、`1 hour 30 minutes`、`直到 18:00` 和 `until 6pm`；有限时长为 1 分钟至 24 小时。
- 分类：自定义与内置分组、应用／网站数量、编辑、复制内置分类、复制列表、JSON 导入导出和确认删除。内置列表为本项目自行整理的预设，不承诺与 Raycast 的数量一致。
- 应用与网站以可删除标签显示。输入框和菜单位于同一个 Launcher 窗口，避免独立弹出窗口抢走输入焦点；保留中文输入法组合过程。
- `www.baidu.com` 规范化为 `baidu.com`。完整域名匹配自身和子域名，不匹配类似 `notbaidu.com` 的域名；`gemini` 等单段规则匹配完整域名标签。
- 切换专注：无会话时复用上次配置；有会话（包括暂停状态）时完成当前会话。首次没有配置时进入表单。
- 悬浮专注条显示目标与计时，可暂停、恢复、完成、编辑、重新开始、取消或移到菜单栏。菜单栏提供目标、暂停时长子菜单、编辑、完成、取消和分离。
- 有限时长到期自动完成；休息结束只提醒，由用户主动恢复。睡眠期间不计时；唤醒后恢复睡眠前正在运行的会话。手动会话在进程重启后恢复为暂停状态；系统自动会话按下方联动规则恢复。
- 完成与取消分别写入本地记录，保留最近 200 次；本轮不提供历史统计界面。

## 拦截与恢复

功能默认关闭，启用时使用共享辅助功能授权流程。关闭、撤销授权或停止模块时暂停会话并请求恢复被重定向的网页。

应用使用正常退出，不强制结束进程；Keylane、访达、系统设置和登录界面始终保留可用。应用有未保存工作时尊重其保存流程。临时放行到期时，前台应用先显示屏蔽提示，切走后退出。设置可选择 1／3／5／10 分钟或不允许临时放行。默认 3 分钟、播放通知声音、不恢复退出的应用、不允许所有网站。

网站通过原生 Apple Events 控制 Safari、Chrome、Edge、Brave、Vivaldi、Opera、Chromium、Chrome Canary 和 Arc 的标签页。首次需要控制正在运行的浏览器时请求自动化权限；运行中缺少权限或遇到已知不支持的浏览器时暂停会话并显示提示，避免误以为网站仍受到屏蔽。仅承诺这些浏览器的脚本接口接入，实际版本兼容性需要安装版验收；Firefox、其他浏览器与嵌入式网页暂不支持网站重定向。

重定向前先原子保存恢复记录，再比较当前 URL 后写入。暂停、结束或临时放行时只恢复仍停留在对应屏蔽页的标签；用户自行改变、关闭或移动的标签不会被旧 URL 覆盖。浏览器退出后保留恢复记录，后续恢复时重新核对对应屏蔽页。故障恢复文件读取失败时保留原文件并停止新的网页写入。

“恢复已退出的应用”只尝试重开在原会话结束前观察到、且与专注退出请求及时对应的应用；晚到、无法归因的退出不自动重开。自动化失败与存储失败必须显示，不作为成功完成处理。

## 通知

阻止访问时显示顶部提示、应用图标、可配置的临时放行按钮及黄色屏幕边缘光效。完成时显示顶部完成提示和绿色光效。通知和光效使用不激活的原生面板；边缘面板忽略鼠标事件，覆盖各显示器，支持全屏空间。减少动态效果和降低透明度设置生效。通知出现期间暂时隐藏悬浮条，避免两者重叠。

## 系统专注模式联动

采用 Apple 原生 [`SetFocusFilterIntent`](https://developer.apple.com/documentation/appintents/setfocusfilterintent) 接口。启用 Keylane 专注并完成权限授权后，在「系统设置 → 专注模式 → 选择模式 → 添加过滤条件 → Keylane」选择一个或多个分类、屏蔽／允许模式，以及可选目标。分类包括内置和自定义分类。

- 系统开启过滤条件时，以所选分类的应用／网站并集启动不限时会话；切换到不同配置时结束旧自动会话，再启动新会话。关闭系统专注或移除过滤条件时完成对应自动会话。
- 手动会话始终优先。系统开启、切换、关闭都不替换或结束已有手动会话；手动会话结束后，不会补开之前被忽略的系统会话。下一次系统过滤条件发生变化时才重新应用。
- 自动会话记录拥有者 ID；完成、取消、重新开始和暂停都维护该来源。手动完成／取消自动会话后，相同系统通知不会将它重新开启。系统联动状态显示在专注条的计时文字中。
- Keylane 保持运行时，隐藏 Launcher 不影响接收系统变化。启动和激活时通过 `current` 核对当前过滤条件；重启仅恢复仍匹配系统配置、且未由用户暂停的自动会话，不把退出期间算作工作时间。读取系统状态出错时保留现有状态，不将错误当作关闭通知。
- 系统触发不弹出首次权限请求。需先启用 Keylane 专注；网站规则需先通过手动会话完成浏览器自动化授权。缺少授权或所选分类已删除时报告错误，已有自动会话暂停；不会降级为空白允许列表。
- 本轮是系统专注模式控制 Keylane 会话。没有反向切换系统专注模式，也没有在 Keylane 完全退出时唤起它的后台扩展；完全退出期间不执行拦截，重新运行后核对当前系统配置。

SwiftPM 打包显式调用 Apple 元数据处理器，将同次构建的 `swiftconstvalues` 转为 `Contents/Resources/Metadata.appintents`，在签名前加入应用。安装包验证要求存在 FocusConfiguration 系统协议、分类实体和完整参数；缺少注册信息则打包失败。

## 数据与边界

数据保存在应用支持目录的 `Keylane/Focus` 下；分类文件为 Keylane 自己的版本化 JSON 格式，未声明兼容 Raycast 导出格式。读取失败不覆盖原数据；分类导入全量校验后提交，导出可重新导入。

AI、Apple Shortcuts 原生动作和 Focus deeplink 尚未接入。没有宣称与 Raycast 全部功能逐项等同。

## 验证

- `Tests/KeylaneCoreTests/FocusSystemFilterTests.swift`：系统／手动所有权、重复通知、分类合并与失效、旧数据迁移和暂停恢复决策。
- `Tests/ReleaseTests/test_app_intents.py`：系统注册元数据与匹配构建来源校验。
- `Tests/KeylaneCoreTests/FocusTests.swift`：规则规范化、域名边界、两种模式、允许全部网站、暂停／恢复计时、临时放行到期、时长解析、分类导入导出、状态持久化和完成／取消记录。
- `bash scripts/verify-focus.sh`（需要本机图形会话及有效 Apple Development 身份）：使用独立偏好、临时数据目录和模拟浏览器传输，验证重定向／恢复及保留用户改过的标签；使用脚本生成的专用应用验证正常退出与恢复；渲染实际 SwiftUI 分类、会话、列表、悬浮条和通知视图，并验证输入框；通过空白屏蔽分类模拟系统开启、切换、关闭、重启恢复和手动优先，不修改用户的系统专注模式。
- 该脚本不构造生产 Model／Delegate，不使用真实浏览器自动化，不退出用户已有应用。生成的应用使用随机测试标识，策略限定为屏蔽该应用。
- 安装版仍需验收真实浏览器权限、未保存文档、中文输入法实际组合字、多显示器和全屏空间、睡眠唤醒，系统设置中过滤条件的真实显示及开启／切换／关闭投递，以及屏幕光效动画观感。合成输入和模拟标签不等同于这些实机验收。

本轮验证结果：283 项完整 Swift 回归、25 项发布脚本测试通过；原生验证已通过表单自动聚焦、中英文输入、共享菜单栏切换、逐显示器光效面板不抢点击／焦点、专用应用正常退出→通知点击临时放行→重新开始→完成恢复，以及模拟标签重定向／恢复。系统联动隔离验证通过自动会话开启／替换／结束、手动会话优先、重复投递抑制、失效分类保护、用户暂停保留和进程重启恢复；未更改真实系统专注模式。预览仅使用生成的数据与专用应用，不包含用户桌面截图。

系统联动安装包验证：Release 构建通过，Apple 元数据处理器从同次整模块常量输出提取过滤条件；Apple Development 签名 DMG 的元数据、完整文件清单、版本、架构及严格签名检查通过。系统设置中的实际入口显示及真实模式切换投递仍待安装版验收。

## 合并前可靠性复核

浏览器写入必须取得稳定标签 ID，并同时核对浏览器进程、原窗口／位置、唯一 ID 和唯一预期 URL。比较与写入前再次验证；相同进程中已移动、ID 被替换、相同 URL 有多个匹配或缺失身份时跳过，不按位置或网址猜测。恢复只匹配应用创建的唯一随机屏蔽页。Safari 等浏览器若脚本接口没有稳定标签 ID，将报告无法安全识别并暂停网站拦截，而非降级为位置写入。

浏览器不在运行或刚重启返回空快照时，保留原始网址和屏蔽页。新进程稍后出现唯一屏蔽页及稳定身份时可重新绑定并恢复；用户手动导航的网页不变。自动恢复每 2 秒重试，最多 20 次、最长 7 天；达到任一上限停止自动处理，保留原记录和标记供检查。旧版没有身份的记录不猜测恢复。恢复失败或仍有歧义时显示待恢复状态，不将结束会话等同于所有网页已恢复。恢复日志已有 4000 条时，若仍有网页需要屏蔽则暂停专注并明确告警，不覆盖旧记录。

应用退出请求在发出前按 PID、启动时间及所属会话持久化。保存对话框取消、请求拒绝或进程身份不明时，不在定时器／新会话中再次发起；同一进程只尝试一次。会话结束时保存当时的恢复偏好，符合保守归属条件且已观察到退出的凭据跨会话、跨进程重启保留；仅在当前策略允许时恢复，恢复成功后才确认凭据。重开发生瞬时错误时自动重试最多两次，仍失败则保留记录。AppKit 只能确认正常退出请求已发出，不能确认用户是否取消保存对话框；未确认发出或未及时观察到退出的进程不授权自动重开。请求后约 100 毫秒主动复核，仍在运行即标记归属不确定；即使尚未复核，也只接受 1 秒内观察到的退出。保存对话框、慢退出或进程身份不明可能因此跳过自动恢复；保守跳过优先于把用户手动退出的应用重新打开。完成、取消或 Keylane 退出后未观察到结束的请求不补记，即使进程随后立即退出。重新开始会转移原会话所属凭据。

允许所有网站的策略生效后立即取消旧任务并恢复能安全识别的网页。浏览器授权拒绝会停止后续授权链并抑制同一浏览器的重复请求；用户取消准备后不再请求其余浏览器，也不创建会话。权限之后在系统设置中授予时，被动检查通过即可继续。启动／唤醒的恢复意图在重叠刷新中保留，旧代次的完成不会清除新代次状态。

`KEYLANE_FOCUS_SAFETY_ONLY=1 bash scripts/verify-focus.sh` 使用注入浏览器、权限响应和临时数据，覆盖上述标签歧义、位置复用、重启空快照、有限重试与过期、恢复报错、允许全部策略取消及授权链取消。该模式不调用真实浏览器、系统专注或权限请求；默认模式保留原有专用应用与 UI 隔离验证。

可靠性复核结果：283 项 Swift 测试、25 项发布脚本测试、新增纯合成安全检查和默认隔离验证通过；默认验证另覆盖同一专用应用在后续会话仍可退出并恢复。最终 Release、Apple Development 签名包、过滤条件注册元数据与严格安装包检查通过。没有操作真实浏览器、系统专注模式或权限。

P2 补充复核（2026-11-20）：保留启动失败后释放 URL 锁、有上限的退避重试及日志满时报告错误的已有修正，并补充控制器级合成用例，确认日志满会暂停且保留全部原始网址、连续启动失败最多尝试 3 次并保留持久凭据。另覆盖同一会话内取消保存后很快手动退出、归属超时、归属不确定状态持久化。288 项 Swift 测试、25 项脚本测试与 35 项纯合成安全检查通过；最终 Release、Apple Development 签名包及 Focus 过滤条件元数据检查通过。本轮不运行真实浏览器、系统专注、权限或默认专用应用验证。
