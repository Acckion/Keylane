# 模块 AI 动作与样板

基线：dev `5f44ac1`，交付前整合云端听写 `b9eb188`。本批实现模块 AI 接点和三个样板：剪贴板文本摘要、剪贴板文本翻译为简体中文、现有文件问答迁移。后两条文件入口 `ask-files`／`ask-finder` 沿用原 ID、设置键和窗口。

## 结构与添加方式

- `AIActionDefinition` 是 KeylaneCore 中的纯声明，引用既有 CommandID，包含标题、指令和 UTF-8 输入预算。`AIActionContext` 是输入快照及精确内容指纹，不包含凭据或访问书签。
- `LauncherModule.aiActions` 只补充普通命令的 AI 元数据。注册表验证声明、重复项与本模块命令引用；搜索、热键、菜单仍走原 invoke。`Command.aiExecute` 可接受宿主提供的来源，注册表拒绝其他模块的来源。声明枚举不读取正文、不创建请求。
- 模块用 `AIActionSource` 提供惰性 load 和 isCurrent；公共会话不包含 clipboard／files 业务 switch。来源工厂分别在 ClipboardAIActions 与 FileAIContextSource，提取工作在后台执行。
- `AIActionSession` 管理准备、发送前来源核对、固定模型目的地、结果和代次；短动作不创建聊天资料库或自动写入历史。
- `AIRunHandle` 是聊天与模块动作的共同传输循环，负责增量、进度、结束和取消。聊天通过 `prepareTools` 在请求开始时创建现有 `AIToolRun`，保留确认、可用性与取消检查；模块短动作默认不启用工具。AIConversationSession 仍拥有原聊天、项目和历史状态；FileAIController 已移除独立模型请求循环，只保留原窗口、文件范围和设置桥接。
- `AIActionResultView` 复用 AIConversationMarkdownBody 与 AIResponseProgressView。模块页面复用 LauncherCreationForm 和原动作／回车／Esc 宿主；文件窗口继续沿用原布局，使用同一结果组件。

新增内置 AI 命令时，在所属模块提供普通 Command 和关联 Definition，再提供该模块的 Source 工厂。普通入口使用原命令执行器；对象菜单通过 `Model.runCommand(..., aiSource:)` 传入稳定来源，不直接发模型请求。模块设置继续复用已有命令管理列表。

来源只在用户调用后解析，发送前再次验证。清空／切换动作会取消旧准备及运行，并使旧代次失效。来源取消、停用命令／模块／历史功能或模型目的地变化都不能由一次重新启用恢复旧调用；需要重新打开／准备。可用性流保留 false 事件值，避免快速关闭后恢复时只读到最后的 true。

## 三个样板

| 样板 | 入口与默认行为 | 边界 |
| --- | --- | --- |
| 剪贴板摘要 | 文本记录动作菜单 AI → 总结剪贴板文本；亦注册为普通命令 | 预览单条记录，明确发送后才请求；最多 32,000 UTF-8 字节，结果不自动覆盖记录 |
| 剪贴板翻译 | AI → 翻译剪贴板文本为中文 | 与摘要共用来源、页面、模型和取消；目标语言写在标题中，代码／富文本不冒充原格式往返 |
| 文件问答 | 询问文件搜索、询问 Finder、既有单文件入口 | 默认仅文件名；完整路径和正文仍独立勾选，不隐式下载 iCloud 占位文件或递归读取文件夹 |

剪贴板使用 `.commands` 默认模型，文件沿用 `.files`。不支持的图片／工具不因配置字段而启用，正文仅作为数据；当前默认转换任务不授予工具权限。

文件正文使用共享 AIFileAttachment 读取器。本入口保持单文件 2 MB，使用有界文本／PDF 提取；总正文上限明确为 40,000 UTF-8 字节，问题上限 8,000 字节，最终组合也有上限。超额明确拒绝，不再静默截取四万字符。聊天文件读取的既有默认额度不变。勾选正文时，在准备前后和发送前比较文件身份、尺寸及修改时间；替换／删除后拒绝旧正文快照。只发送文件名时不读取文件正文或推断其内容。

## 继续讨论与生命周期

已完成的源快照和结果可显式加入 Quick AI／当前 AI Chat 的草稿附件。保留现有草稿、附件和活动会话，不重新发请求；预算不足或附件正在读取时拒绝加入而不破坏草稿。复用宿主已有的 existingDraft 进入意图防止已有未发送问题被 Quick AI 的普通命令进入逻辑自动提交。

本批不开放运行中的短动作交接；继续讨论只对完成结果可用。Quick AI→AI Chat 原有活动运行交接仍使用同一会话，已有回归继续验证不重复请求。图片多模态、模型工具、写回源对象、跨模块上下文选择目录和其他业务模块按后续批次接入，不把本批声明为这些能力已经完成。

## 性能与验证边界

根目录及动作菜单只读元数据，不做 OCR、全文读取或网络。AI 页面对宿主的更新只发送运行／准备状态、调用身份及结果是否为空；逐片段正文更新局限于活动结果组件，不转发根搜索评分。输入解析与来源核对有明确预算，旧任务取消后不接纳其结果。

自动化使用本地合成 URLProtocol、临时资料库／文件及隔离偏好，检查原 AI 流程与新增样板。原生窗口夹具链接生产对象文件，使用单独 C 入口与 Bundle ID；不运行真实应用主入口，不创建 Model、读取真实剪贴板或启用后台采集。测试窗口使用本机 Apple Development 签署并校验，截图仅来自这些窗口。

验收包括准备零网络、发送范围精确、旧读取丢弃、来源变更、停用／快速恢复、文件名默认范围、正文显式附加、文件替换、草稿保留及无自动提交；保留原文件问答、Quick AI／Chat、提供方、历史／项目／分支与取消回归。

这些结果不等于真实提供方、真实剪贴板、中文输入法或安装版持续性能验收。CPU、内存和滚动性能的前后对照尚未测量；不以公共组件复用直接宣称性能提升。

## 模块上下文与第二批入口

模块通过 `LauncherModule.aiContexts` 贡献 `AIContextRegistration`（稳定 ID、名称、图标、可用性流、异步目录查询）。目录项只包含标题和 `AIActionSource`，选定后才读取正文。注册表校验上下文 ID 唯一、拒绝其他模块来源，并包装模块激活代次与功能停用代次。停用后再次启用不会复活旧目录或旧读取。

聊天的加号／@ 选择器直接使用登记目录，不维护剪贴板／日历业务分派。目前登记剪贴板文本、已加载日历日程、已加载截图列表。截图仅在选择后做本地 OCR，不重新扫描目录、不读取录屏、不下载云端占位文件，不向模型发送图像。已有“从图片文件提取文字”入口保留。

`aiCommandEntries()` 从普通命令目录派生 AI 命令，静态动作与标记为 AI 的动态提供方使用同一准入规则。聊天 / 菜单包含文字润色、摘要、自定义命令、模块动作及剪贴板附加命令，点击进入原命令预览，不自动发送。导航在同步作用域内保留 Quick AI 会话和草稿；普通离开仍保持原清理行为。

文字命令保留参数编辑与原设置格式，结果改用公共 `AIResultContent` 展示 Markdown、过程和状态；完成后可以通过共用宿主加入聊天草稿。新增“询问所选剪贴板文本”（问题最多 8,000 UTF-8 字节）、“附加剪贴板文本到 AI 聊天”、截图文字摘要与翻译。剪贴板直接附加不会先请求模型，也不清空已有草稿，停用命令会取消尚未完成的附加。

性能边界：目录登记不读取正文；截图 OCR 复用有界缓存与取消，读取期间独立持有授权目录，离开截图页后仍可准备 AI 预览。关闭模块、撤销目录或离开 AI 页面会取消相应任务。正文流式更新继续只影响结果组件。

本批不包含剪贴板全历史工具、图片视觉模型、浏览器正文、片段／便笺 AI、Emoji 语义推荐和日历写入。自动化与合成窗口不代替真实提供方和安装版验收。

## PR #212 审查修复

上下文来源的 `load` 在异步 `isCurrent` 返回后再次核对模块／功能代次和取消状态。即使读取文本时版本检查仍返回 true，检查期间关闭历史功能、关闭后重新开启功能或停用再启用模块，也不能把旧上下文送入草稿。注册表集成用受控 continuation 将调用停在这一精确位置，分别触发三种撤销。

剪贴板附加命令、条目菜单及最终执行入口共用当前 `AIConversationSession.canAttachModuleContext` 的可用性。判断跟随实际 Quick AI／AI Chat 会话及显式选择的模型，并检查历史与附件加载状态；不使用只表示 `.files` 路由可用的 `AIConfiguration.isAvailable`。文件问答配置失效不会禁用有效的聊天附加入口，反之，只有文件问答可用时不能误启用聊天附加。已有草稿和运行中的生成不因可用性判断被清空或重新发送。

相关回归在 `verify-launcher-modules.sh` 和 `verify-file-ai.sh` 中使用合成上下文、独立偏好与模拟传输，不读取用户真实历史，也不调用模型服务。最新 dev 的模块级评分失效用例与上下文用例均保留。真实账户与安装版验收不由这些自动化替代。
