# 暂存架

实现状态：第一版原生底层与界面已接入；**真实跨应用拖放尚未验收通过，不能标记为可发布或与 Dropover 完全等效**。

## 入口与交互

通过「新建暂存架」「从剪贴板创建暂存架」「选择暂存架」命令打开，或者将内容拖到菜单栏的暂存架图标。拖动内容时左右摇晃指针会在附近显示新架。暂存架设置可调整晃动灵敏度。按键激活默认关闭。开启后，拖动时单独按住选定的修饰键即可唤出，初始按键为 Command。自动唤出的架只显示顶部把手与投放提示，拖入时亮起蓝色轮廓，实际内容进入后过渡到普通样式。设置还提供快捷键编辑、默认位置、添加到新架或复用现有架、忽略应用以及可选的刘海投放。刘海入口只出现在系统报告有摄像头凹口的显示器上。拖拽唤出的架在拖动结束或取消后若仍为空且没有接收投放，会自动关闭；已有内容、已接受异步投放及手动创建的空架不会因此关闭。

首次加入默认快捷键为 ⌥⇧Space、⌥⇧A、⌥⇧S。只安装一次，不替换既有绑定，也不覆盖 Keylane 中已占用的组合。系统注册冲突仍由现有快捷键管理器报告，并保留独立可用的快捷键。可在设置中的共享命令列表改绑或关闭。当前「选择暂存架」聚焦第一个打开的架，没有 Dropover 的编号选择界面。

紧凑态为正方形，复用 Launcher 的 NSGlassEffectView、连续大圆角及非激活面板，无标准红绿灯按钮。左上关闭，右上展开/收起；中央缩略图可作为拖入/拖出区域，底部文件名胶囊打开详情。展开态使用更宽的内容面板：返回按钮、内容数量、设置与排序菜单、网格/列表切换，以及「在 Finder 中显示」。固定、重命名、复制、粘贴、清空和取消加载从架设置菜单执行。外观跟随 Keylane 的系统/浅色/深色选择；缩略图在后台生成。

激活架后，⌘W 关闭、⌘C 复制、⌘V 粘贴、Delete 移除选中内容（收起态无选择时清空；展开网格须先选择）、Space 打开文件 Quick Look。关闭保留最近记录，清空只移除暂存记录。固定架持续保留，最近历史最多保留 10 个未固定架；重启后可通过菜单重新打开。成功拖出默认关闭窗口，可在设置改为保持打开；取消或拒绝保持内容。

默认向目标提供系统复制/移动协商，同卷目标可能选择移动。按 Option 可复制；设置中的「默认复制到目标」限制为复制。源文件的移动由接收应用执行，Keylane 不在拖动结束回调执行移动或删除。

## 与下载、截图管理联动

下载扩展和截图管理现在共用 `DropShelfController.addFiles` 入口，可从各自 Launcher 操作菜单手动加入，也可单独开启新文件自动加入。保留暂存架既有的新建/复用规则，不替换系统剪贴板，不自动启用已关闭的暂存架。截图侧复用现有截图管理监听，下载侧由下载扩展管理获授权目录；具体范围、文件稳定性限制和验证见 [下载与暂存架联动](DOWNLOADS-SHELF.md)。

## Launcher 内管理

在 Launcher 搜索「暂存架」打开管理页，或在菜单栏选择「管理暂存架」。方形卡片网格随窗口宽度换列，每张卡片显示一个暂存架，并复用浮动架的液态玻璃与缩略图叠放。单项用名称作为底部胶囊，多项显示数量。搜索匹配架名称及其内容，每次打开 Launcher 时按最近使用顺序排列。本次打开期间，图钉状态实时更新，现有卡片保持位置。新建架子追加到网格末尾，下次打开时按更新后的使用记录排序。筛选提供全部、已固定和未在桌面显示。

用方向键在网格中移动，搜索框有文字时用 Option＋←/→ 横向选择。回车或点击卡片打开对应的浮动架。图钉实时反映对应暂存架是否在桌面显示。固定时架子会淡入桌面、避开已显示的架子，并保留 Launcher 的键盘焦点。取消固定会关闭对应窗口，保留暂存记录。右上角菜单提供重命名、从桌面关闭、删除暂存架。从管理页关闭时保留暂存记录，空架也可在重启后从管理页打开。删除整架需要确认，只移除暂存记录及暂存架持有的内容。

从「设置 → 暂存架 → 文件夹观察」可选择截图和下载文件夹，目录会同步到对应的截图和下载设置。

## 内容与数据边界

- Finder 文件和目录保留安全作用域书签，不复制进仓库或私有缓存。拖出前重新检查可读性；改名/移动后重新解析书签并更新记录。源消失时从架中移除并反馈；无权限时报告失败。
- 文本、普通链接、PNG/TIFF/JPEG/GIF/HEIC 原始图片数据可接收；链接不会自动下载或打开。图片保留原数据，内容哈希用于重复判断。文件、文本、链接各按自身标识去重，不按显示文件名去重。
- 普通粘贴与真实拖放是不同入口。NSFilePromiseReceiver 仅在原生拖放回调内调用；普通剪贴板仅读取可直接消费的文件 URL、图片、链接或文字，不能直接兑现文件承诺。
- 每次文件承诺拖入使用同一个独立批次目录，在后台接收；多接收器共用该批次目录，在原生接受回调内同步登记全部请求；成功的 reader 在其文件协调读期间立即把输出隔离至私有暂存目录。批次按来源顺序提交，不因回调完成先后重排。失败可部分成功，并给出错误。
- 取消、清空、关闭或模块停用撤销批次提交资格，不假设来源应用已经停止写入。迟到回调不能恢复条目；全部回调完成后清理失败/取消残留。启动时清理上次中断的私有目录。
- 外部引用永远不进入清理器；清理只扫描 Keylane 所有的 Assets/Incoming。已经拖出到外部位置的文件不会被清理器删除。复制到剪贴板后保留授权至架关闭；Quick Look 单独持有预览期间授权并随架关闭释放。
- 文字、图像、文件承诺和记录均只存本机。生成内容单项 64 MiB、每架 1000 项、记录总文件 32 MiB 上限，持久化失败回滚内存记录。目录 0700、记录和生成数据 0600。临时导出文件在后续进程启动时回收，避免拖出期间被提前清理。

不包含云上传、付费服务、监控文件夹、缺口投放、分享扩展、脚本、停靠架、编号选择器、架颜色或其他第二阶段设计。没有第三方私有代码、品牌或用户参考图素材。

## 架构

`DropShelfStore` 在 KeylaneCore 管理可恢复记录、外部引用、私有资产和事务回滚。`DropShelfController` 管理模块服务、菜单栏、窗口、摇晃及偏好。`DropShelfWindow` 承接原生面板、列表与输入输出；`DropShelfPreview` 承接紧凑面板的原生拖放。`DropShelfReceiving` 分离批次事务与 AppKit 接收器，允许可控异步测试；生产适配器仍使用 NSFilePromiseReceiver。

模块经 LauncherModuleRegistry 注册命令、设置和服务，管理页复用 Launcher 的滚动与筛选组件，并与浮动架共享缩略图加载和预览；菜单栏经现有 MenuBarRegistry 管理；新增拖入覆盖层只属于相应状态项，在隐藏/停用时移除。Quick Look 沿用 FilePreview，使用独立的 shelf owner，不抢用其他模块的预览生命周期。

官方研究来源与日期见 [设计调查](design/DROP-SHELF.md)。用户在 2026-11-17 确认相关行为与 Dropover 一致，并提供正方形液态玻璃参考。尚未达到完全一致的部分在此明确列出，不作为已完成能力。
