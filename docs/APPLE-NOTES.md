# Apple 备忘录集成

## 首版范围

- 在主搜索运行「搜索 Apple 备忘录」，按标题或正文检索，选中后按回车在 Apple 备忘录的独立窗口打开。锁定笔记仅按标题匹配。最近删除文件夹通过 Notes 自动化返回的文件夹名称识别。
- 「新建 Apple 备忘录」使用 Keylane 的共享表单快速输入标题与正文，保存到 Apple 备忘录的默认账户和文件夹，再打开独立窗口。可通过命令设置配置快捷键。
- 后续编辑由 Apple 备忘录的原生窗口处理，可以使用该账户支持的富文本、附件和同步。Keylane 不覆盖或删除现有 Apple 备忘录，不另建笔记数据库。
- 附件文字、手写、扫描件和图像等检索使用 Apple 备忘录自身的搜索。Keylane 结果最多显示 60 条。搜索结果只保留在页面会话内，离开页面即清除。

Raycast Notes 的快捷新建、检索和独立编辑窗口是首版的交互参考。Apple 备忘录管理独立窗口的显示层级。参见 [Raycast Notes](https://manual.raycast.com/notes) 和 [Apple 备忘录搜索指南](https://support.apple.com/guide/notes/not18ab658ed/mac)。

## 验证与权限

- 实机通过 Notes Apple Events 授权、测试记录新建、标题与正文检索、按 ID 定位、独立窗口、测试记录编辑并读回。测试只修改专门新建的记录，结束后将这些记录移出活动文件夹。
- 实机通过 Keylane 自动化代码新建、搜索和打开独立测试记录，验证中文和 HTML 特殊字符，以及测试记录移入最近删除后的搜索和打开过滤。
- 首次执行可能弹出 macOS 自动化授权。若先前拒绝，可在「系统设置 → 隐私与安全性 → 自动化」检查 Keylane 对备忘录的权限。最终安装包的首次授权与启动器视觉交互仍待验收。

## 旧 Keylane 便笺

升级会移除旧便笺功能、偏好值、共享数据库中的便笺行及其全文索引，并压缩数据库和截断写入日志。旧数据不迁移到 Apple 备忘录，链接及文字片段仍保留。此前手动导出到其他目录的文件由用户管理。
