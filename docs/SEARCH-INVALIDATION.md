# 搜索定向失效：第一批

基线：origin/dev 1eea4a6。保持现有 UI、命令 ID、设置和排序规则。

模块搜索通知通过 `searchInvalidations` 携带 ModuleID；宿主可用性和注册变化仍触发全局失效。旧 `searchUpdates` 保留为兼容投影。搜索保存当前查询的逐条评分，包括未匹配条目；模块更新移除所属评分，其他候选只有评分字段完全一致才复用。新查询、偏好/排名输入变化、全局失效、注册表变化或 60 秒期限均放弃复用。

候选每次刷新仍实时枚举、核对可用性并重新生成展示结果。因此关闭功能、删除记录和展示字段更新不会被旧结果挡住。此批减少评分，不缓存 provider 查询，也没有停止全局排序或完成异步查询取消。

`LauncherCommandSearch.diagnostics` 记录最近一次的评分数、复用数、整次缓存命中与单调时钟耗时，不记录查询或用户正文。应用和文件共享此路径，无需再添加业务分派。

验证：`bash scripts/verify-launcher-modules.sh`。固定合成 2000 个应用和 1 个文件，文件更新后评分从 2001 次降至 1 次，其余 2000 次复用，结果与新搜索对象全量重算一致。覆盖候选删除、未发应用通知但可用性改变、全局失效与查询改变。单次合成计时不作为真实用户性能提升比例。

额外验证：330 项 Swift 测试、27 项发行脚本测试与版本检查通过。全应用构建曾因本批编辑误删相邻 presentationUpdates 声明而失败，随后恢复声明并撤销诊断用的页面拆分；未保留无关 UI 改动。恢复后完整应用构建通过（44.27 秒）。

待验收：真实首次/重复查询、静置、滚动 CPU/内存与安装版交互。后续再做 provider 快照、增量排序与异步预算，不能把本批描述为全部搜索架构迁移完成。
