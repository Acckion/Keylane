# 模块 AI 指令声明与请求快照

前序 PR：#218 → #221 → #223 → #226 → #227。基线 dev `036cfd7`，在独立工作树整合 #227 `f66fd05`；#226/#227 尚未合并，本批依赖它们。

模块使用 `LauncherModule.aiInstructions` 声明静态工具用法说明；目录验证只核对文本，不创建页面、读取来源或调用权限/网络。每模块最多 4096 UTF-8 字节；宿主去重、按 ModuleID 排序，总说明最多 16384 字节。重复 owner 的冲突声明拒绝，不静默覆盖。

注册表赋予 owner 并覆盖贡献者自报的模块说明。内置剪贴板、索引文件与 AI 路径工具为样板。说明不是新权限，也不改变 native 审批、引用、目录授权或撤权逻辑；来源正文/搜索结果仍视为不可信数据。

会话提交前冻结选中的工具声明与对应模块说明，先验证再改变草稿；发送边界重查冻结工具可用性后才获取提供方租约。目录在期间变化不能将旧说明和新工具混合。模块禁用/替换使旧工具无法发送，选择变化仍取消当前请求。工具总开关关闭、空选择、未选模块或没有模块 owner 的工具不注入说明。

已有项目/会话/显式指令保持原文；模块说明作为带宿主边界提示的工具用法指导排列在前。不写回用户指令、历史或偏好。该提示不是模型层面的安全保证，权限只由原有执行器判定。

合成测试核对实际 OpenAI/Anthropic 请求体、选择过滤、空集/总关闭、元数据一致性、发送前租约、无效说明保留草稿及目录验证回滚。生产组件/安装版和真实模型验收单独记录，不自动合并/安装/发布。

本地验证：完整应用编译、411 项 Swift 测试、27 项脚本测试、目录事务与共用会话/模拟传输/工具集成通过。精确最终头和远端 CI 记录在本批 PR；未访问真实数据或模型，未安装/合并/发布。
