# 文件索引重启恢复（FILE-01）

2026-11-23，基于 dev `5b4378ce`（已整合 `99c7a373` 打包修复），分支 `fix/file-index-restart-recovery`。本批只实现持久索引恢复；正文索引拆分、查询合并和缓存预算留给后续批次。

## 行为与安全边界

- 索引库保存已完成写入的 FSEvents 位置，以及索引规则、授权根目录、恢复目录、自动排除目录、卷和根目录文件身份的配置签名。读取与签名计算在后台队列执行。
- 配置和根目录身份一致时，启动读取现有索引，从保存的位置回放退出期间的事件。启动阶段到达的搜索不会绕过恢复检查另起全量扫描。内置模块不再在服务恢复时无条件扫描。
- 全量或增量扫描开始前作废恢复位置；只有已完成各范围的写入/清理、未取消且监听成功时才保存新位置，同时保存待重试路径。中断可能留下部分索引更新，但没有可恢复游标；下次使用完整扫描恢复。文件写入和位置提交按同一串行写入队列排序，不宣称整轮扫描是单次原子事务。
- 没有恢复记录的旧数据库、配置/授权/目录身份变化、事件丢失或编号回绕都会补扫。暂不可读或离线路径保存到待补扫集合，清理时保留这些子树的旧记录，其他已完成区域照常删除失效记录。重启只重试未完成范围；目录身份恢复/变化时重新核对配置。监听失败时不保存可复用位置，保留原有离线条目策略。旧版首次升级需完整建立一次基线。
- 过滤掉的事件仅在没有待扫描路径、未完成分类或恢复任务时推进游标。退出/暂停/禁用会取消监听与恢复，旧回调不能修改新运行状态。历史回放不参与实时一分钟缓存风暴判断。
- 新增单行恢复表，保留用户设置键、文件数据库记录和原有全文索引；不清空用户数据库。

## 隔离验证

- 453 项 Swift 测试通过。首次受限环境的系统文件协调与 OCR 测试失败，允许访问相应 macOS 服务后全量重跑通过；未跳过测试。
- 30 项发布脚本测试及版本检查通过。
- 原有真实文件集成通过：中文/多词/正文/PDF、忽略规则、暂停恢复、授权、离线保留、FSEvents 更新与统计。
- 新增 `KEYLANE_FILE_TEST_SOURCE=Tests/Integration/file-restart-main.swift bash scripts/verify-files.sh`：2000 文件初次建立、三次无变化重启、立即查询、真实退出期间新增/删除/重命名、140 项历史构建文件、规则变化、授权丢失/恢复、缺失恢复记录及立即关闭运行时。新增真实 chmod 不可读目录的局部保留、重复启动、权限恢复补扫，以及扫描中发现自动排除目录后的复用。
- 使用仅测试构建启用的注入入口验证用户/内核丢事件、编号回绕和根目录变化需要全量恢复。此项是注入信号验证，不代表制造了真实系统丢事件。
- 同一隔离数据集的初次基线消耗 CPU 0.2616 秒；三次无变化恢复为毫秒级（不同轮次约 0.002–0.008 秒）。包含控制器启动与等待回放结束，冷启动不含生成测试文件；不是整机能耗或长期内存结果。用数据库哨兵确认无全量扫描，而非仅凭耗时推断。

## 本机发现并补充修复

首次安装验证遇到 774 项读取失败；原先“一项失败就不保存游标”的保守实现导致再次启动仍会全扫，因此未将该轮安装记作通过。现改为持久化待重试路径，并以每批 512 条元数据清理已完成区域；对失败子树保留旧记录。不存在的目录项与断链/暂时不可读路径分别处理，避免为了跳过扫描误删除旧记录。本机首次基线约 90 秒，后续结果另录。

## 本机交付

安装、签名校验和同数据重启对照完成后补录。安装版交互与长期能耗由实机复验，不能由隔离测试推断；本批不宣称达到按时间平均低于 100 MB 的目标。
