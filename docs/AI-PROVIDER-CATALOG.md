# AI 提供商目录同步

API Key 保存后由 `AIConfiguration.refreshModelCatalogs` 请求同步。应用完成启动后由宿主启动 `AIProviderCatalogSync`；目录服务监听已保存连接，首次或新增连接自动发现，无需进入设置或展开菜单。关闭 AI 时取消目录请求。

## 缓存与公共入口

- 模型与元数据在现有 `aiConnections.v1` 的连接目录中持久化；可选 `providerCatalogs` 仅保存目录更新时间和已发现模型 ID，兼容旧配置，无密钥。
- 设置、Quick AI、AI Chat、命令共用 `AIConfiguration.state.connections` 与 `AIModelMenuCatalog`。菜单读取内存快照，重启先读持久缓存；展开菜单不发请求。
- 缓存有效期 6 小时，服务每 30 分钟检查一次；连接变更也检查，失败至少退避 5 分钟。设置中的「同步模型」强制刷新。
- 同一凭据所有者、接口和协议只发一次目录请求；目录结果原子发布，保留模型 UUID、默认选择和隐藏状态。发现结果补全名称、上下文、图像与工具能力；未提供的数据保持未知，不伪造速度/智能评分。
- 已发现的模型从上游目录消失时标为不可用，保留历史与选择；重新出现时恢复。手动配置但从未出现在目录的模型不自动删除。
- 失败、空目录、禁用、移除连接和过期请求不会覆盖有效缓存。目录认证使用与生成相同的凭据路由；状态不保存提供商错误正文或凭据。
- 通用目录适用于 API 预设、已保存的本地 Ollama 和高级连接。订阅账户保持原来的账户目录生命周期；自定义 YAML 保持其明确声明的模型列表，不自动扩写配置。
- 提供商卡片按凭据连接汇总，避免自动发现后显示数百个重复 API Key 行。

## 验证

`KEYLANE_PROVIDER_CATALOG_ONLY=1 bash scripts/verify-file-ai.sh` 独立运行无系统 sheet、无真实密钥的目录回归：大于 1 MiB 的目录、元数据、自动发现、重启缓存、共享选择菜单、UUID/默认值/隐藏状态、过期刷新、失败/空响应与禁用取消。

附加 `KEYLANE_VERIFY_OPENROUTER_PUBLIC_CATALOG=1` 可只读验证公开 OpenRouter 模型目录。不使用用户 Key，不发送模型生成消息；不能替代账户权限和实机 UI 验收。

本轮已通过：317 项核心测试、27 项分发脚本测试、独立目录回归，以及公开目录实测（477 个模型）。最终调试构建的 Apple Development 签名 DMG 已通过包布局、元数据、架构、许可和签名校验；不是发行构建，未安装。完整 AI 界面集成脚本在受限环境的系统界面阶段中断，本轮未完成安装版 UI 或用户账户权限验收。
