# 阶段 1 实施与验收记录

版本：0.5.1（2026-11-10）。状态：核心交互完成本轮验收，完整阶段验收仍未完成。不是完整产品，也未进入阶段 2。

## 实现

- 主面板继续使用 NSGlassEffectView；macOS 27 的 effectIsInteractive=false，整窗不启用按压效果；按钮仍使用原生玻璃样式。
- 主窗口保留 760×470 pt、28 pt 圆角和 40 pt 列表行；菜单分别锚定左右下角。
- 点击内容空白关闭菜单；Escape 返回；隐藏/重新显示清理菜单状态并恢复搜索焦点。
- AppKit 原生搜索输入：标记文本期间不解释上下/回车/Escape；菜单使用 selectText 明确启动编辑，避免焦点指向控件但无法直接输入。
- 统一窗口隐藏入口；外部点击、失焦时隐藏启动器，独立设置不使用该规则。
- 重开应用入口、当前鼠标屏幕居中、记住位置及可见区限制。
- 系统/浅色/深色偏好，设置与主窗口统一响应；减少动态效果、透明度和增强对比度在视图中适配。
- 独立设置；配置项级搜索与定位；修复搜索结果仅选行不跳转、关于打开错误页；设置页与路由同步。
- 退出清理鼠标监听与快捷键句柄。

## 自动验证

5 项 XCTest 通过：原有计算器、搜索、SQLite 数据测试；新增配置项多语言搜索、空/缩短列表导航边界测试。release 构建通过；安装包可执行权限和临时签名校验通过。

这些测试不覆盖真实输入法、窗口动画或跨屏交互。

## 实机已观察

通过 CUA 在已安装版本上验证：

- 应用启动，搜索框可输入英文应用名称。
- Cmd+K 打开选中应用的动作列表，搜索焦点进入菜单。
- 菜单无需额外点击可输入 Finder 并筛选，Escape 恢复主搜索。
- 100 次 Cmd+K / Escape 连续开关后仍保留主搜索焦点，能继续输入及打开设置。
- Cmd+逗号打开独立设置。
- 搜索 dark，点击“外观”结果能进入通用页并显示目标配置。
- 浅色/深色切换有效，两种设置窗口截图已检查；结束时恢复“跟随系统”。
- 工具栏关于入口定位到“关于 Keylane”，显示 0.5 开发版。
- 获取过主窗口和动作菜单截图；材质受桌面背景影响，仍须结合实际桌面观察和对照，不判定为像素一致。

最后的设置路由同步、减少透明度背景圆角与 Escape 后备处理经过再次编译及测试；未重复全部 UI 操作。

## 0.5.1 继续验收

### 本轮通过

- CUA 实机点击右下按钮后，动作菜单显示，焦点进入“搜索操作”。
- CUA 实际坐标点击主面板顶部空白，菜单消失，主面板保留，焦点恢复主搜索。
- 原生 ControlGroup 丢失自定义键帽的显示问题已修复为标准按钮文字提示。界面树确认“打开 ↩ / 操作 ⌘K”可见。
- 用户实际鼠标点击桌面/其他应用，再按 Option+Space，明确反馈“先隐藏，再正常唤起”。
- 本地诊断同步记录 hidden:outsideClick（launcherVisible=false）→ shown / shownSettled（launcherVisible=true, launcherKey=true），hotkeyStatus=0。与用户反馈一致。
- 单显示器已记录 displayCount=1，多屏未实测。
- 新增 WindowDiagnostics 是仅本地的 32 条滚动窗口生命周期记录，不记录查询、应用名或文档内容；不会上传。用于区分 CUA 缓存界面树与真实窗口可见性。
- 本轮构建、临时签名验证通过，5 项自动测试通过，0.5.1 已安装。

### 工具限制与结论边界

- CUA 的 AX 点击其他应用可能只操作无障碍控件，不产生实际全局鼠标事件；此时旧界面树仍可返回，不能作为显示/隐藏证据。
- Finder 的 CUA 访问多次超时；改用浏览器工具后，仍未获得可靠的真实跨应用输入。因此普通桌面的隐藏/唤起结论采用“用户实测 + 应用窗口属性记录”，不声称自动化完整覆盖。
- 真实中文候选词输入、多屏/全屏、系统辅助功能开关与动画视觉仍未验收。阶段 1 不标记全部完成，不跳入阶段 2。
