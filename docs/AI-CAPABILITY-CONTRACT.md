# AI 能力契约：第四批第一步（PR #226）

前序架构 PR：[#218](https://github.com/Acckion/Keylane/pull/218) → [#221](https://github.com/Acckion/Keylane/pull/221) → [#223](https://github.com/Acckion/Keylane/pull/223)，均已合入 dev。AI 依赖 #212/#214/#215/#217/#224 也已合入。本批以 dev `37dac2eb3f9a0d0a6817c2d6077f6614cd9ab88b` 重整，只保留模块能力选择增量，不重复交付依赖实现。

## 本次增量

- 注册表赋予工具所属 ModuleID，覆盖贡献者自行提供的 owner；授权目录工具归现有 AI 宿主模块。
- 共用聊天会话通过 `AICapabilitySelection` 缩小工具目录。默认 nil 沿用全部可用工具；显式空集走普通聊天，不要求模型支持工具；显式选择不自动加入新增或无 owner 工具。
- Quick AI 与 AI Chat 共用同一面板、会话状态和运行器。选择只保留到退出应用，不写入偏好或聊天历史；更改选择停止当前调用和审批，恢复选择不会自动重发。
- 工具发现从过滤后的目录生成，不披露未选模块 schema。浏览目录不获取私有来源租约；仅在发送前对选中工具调用 `forRun()`，冻结提供方功能代次，同时保留注册表捕获的模块激活/目录代次检查。选项不替代授权和逐次确认。

## 继承的边界

已合入 dev 的 `AIToolRun` 是唯一工具执行及审批路径。授权路径读取仍叫 `keylane_read_file`，索引临时引用读取仍叫 `keylane_read_searched_file`，不重复注册、不互换参数。逐次/逐页审批、接收方和运行域检查、发送前冻结与披露前撤销、目录授权、PDF/分页限额和私有结果续读保持 dev 实现。

#223 的目录防重入、延迟注册协调、动态替换/卸载、瞬时撤权和服务生命周期不改。元数据浏览推迟提供方租约到发送前；旧目录引用的模块激活检查仍保留，替换、停用/重新启用或卸载后不能恢复。

## 验证与限制

合成回归覆盖默认/空集/显式选择、工具发现过滤、未选与全局关闭时不获取租约、发送前冻结、选择改变取消待审批，以及替换/卸载后旧工具失效。所有源为自建临时文件和命名测试剪贴板，传输模拟，不访问真实用户数据、模型或外部服务。

完整构建、测试和当前准确提交/CI 结果记录在 PR #226。本轮不生成安装包、不安装、不合并或发布，保持草稿；安装版和真实模型交互仍待验收。

本步不是第四批全部完成。资源身份/快照/重新读取见后续 [资源契约](AI-RESOURCE-CONTRACT.md)；模块指令注入、结构化影响模型和扩展提供模型留到后续。
