# 系统设置直达

主搜索可使用中文、英文、常用别名及「蓝牙设置」「System Settings Bluetooth」这样的查询。结果右侧显示「系统设置」，回车打开对应页面。搜索结果通过固定的系统设置链接打开页面，查询内容不进入链接。打开页面不改变系统选项。

47 个入口覆盖网络、通用、外观、显示器、键盘、触控板，以及录屏、完全磁盘访问、麦克风等隐私子页。系统的旧名称和新名称均可搜索。单独搜索「系统设置」保留应用本身的搜索结果。

## 验证

- 在 Apple 芯片 Mac 的 macOS 27.3（26C5035r）对照系统设置窗口标题或侧栏选中项，确认了 47 个目录链接的落点。
- 已安装的 0.15.0 预览版实测主搜索输入英文 Bluetooth、中文「显示器」，回车进入对应系统页面。
- 自动化用例覆盖中英文、常用别名、查询前后缀、唯一标识与 URL，以及应用级查询不会展开整个目录。
- macOS 26 的实际跳转与不同硬件配置待复核。本机未能确认鼠标页可直达，首版目录暂未收录。
- URL 交付失败时在启动器显示反馈。系统可能根据版本和硬件条件调整可用页面。

[Apple《在 Mac 上使用系统设置》](https://support.apple.com/zh-cn/guide/mac-help/mh15217/mac)
