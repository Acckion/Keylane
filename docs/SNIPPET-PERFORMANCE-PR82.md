# 片段搜索与导入性能复测

以 PR #82 的 `01ac2c8` 为功能对照，以 `db6a416` 为优化组。两组使用同一台 Apple Silicon Mac、Release 构建、独立临时签名应用和相同的 6,000 条中英文合成片段、41 个标签及置顶规则。较早的 `dev`（`3827add`）换词搜索 P95 为 175 ms，测试未包含后来加入的标签和富文本。

| 场景 | 功能对照 | 优化组 |
| --- | ---: | ---: |
| 更换查询并读取列表、选中项和标签，P95，36 次 | 162.56 ms | 46.12 ms |
| 同一查询重复读取，P95，24 次 | 30.86 ms | 0.002 ms |
| 批量写入 6,000 条新记录，中位数，4 次 | 1,901 ms | 87 ms |
| 关键词未匹配，P95，6,000 次 | 162 µs | 1.2 µs |
| 最有利的关键词命中，P95，6,000 次 | 0.1 µs | 0.3 µs |
| JSON 读取、解码、去重和构造记录，P95，8 次 | 38.92 ms | 39.90 ms |
| JSON 导出和原子文件写入，P95，8 次 | 10.30 ms | 10.30 ms |
| 旧版快捷链接参数解析，P95，2,000 次 | 14.2 µs | 13.5 µs |
| 动态占位符解析和求值，P95，2,000 次 | 69.7 µs | 70.3 µs |
| 约 60 KB 文本中的光标补全查询，P95，1,000 次 | 3.5 µs | 2.8 µs |
| 950 个占位符的富文本编辑器挂载及布局，中位数，5 次 | 44.68 ms | 45.53 ms |
| 同一编辑器单次插入及布局，P95，16 次 | 15.42 ms | 15.15 ms |

搜索目录缓存置顶顺序、标签和供 Foundation 匹配的文本。同一查询复用最近一次筛选结果。换词仍同步遍历目录，本次混合查询占用的进程 CPU 时间从 3.58 秒降至 0.95 秒。搜索阶段的 physical footprint 采样从 57.21 MB 增至 64.87 MB，包含缓存和进程内其他分配。数据库事务只在覆盖已有 ID 时清理该记录的旧全文索引项，新增记录仍在同一事务中写入正文和索引。批量测试包括打开临时数据库。匹配索引按后缀长度从长到短查找，保留系统关键词冲突判断和同关键词顺序。

采样均为隔离测试。UI 数字包含实际 `NSTextView` 挂载、插入和布局，屏幕显示延迟未测。关键词基准调用实际匹配逻辑，独立应用确实注册了监听器，测试构建拦截全局事件回调并避免向其他应用注入文字。JSON 文件选择和确认交互未计时，富文本布局和 JSON 解码保留原路径。保存草稿的 12 次小样本里，两组中位数都约 1.30 ms，优化组的 P95 波动至 5.58 ms，功能对照为 1.42 ms。

| 生命周期 | 功能对照 | 优化组 |
| --- | ---: | ---: |
| 编辑器退出后，监听启用，区间 CPU | 0.913% | 1.195% |
| 监听启用，区间终点内存 | 58.38 MB | 64.73 MB |
| 仅关闭关键词监听，区间 CPU | 0.010% | 0.008% |
| 仅关闭关键词监听，区间终点内存 | 56.89 MB | 63.28 MB |
| 模块禁用再启用，P95，6 次 | 30.43 ms | 29.24 ms |
| 模块禁用，区间 CPU | 0.005% | 0.004% |
| 模块禁用，区间终点内存 | 65.78 MB | 66.75 MB |

两组在六轮切换中均于停用时清空片段并关闭监听，重新启用后恢复全部 6,000 条。启用监听区间包含编辑器退出后的清理，CPU 按一个逻辑核心计。禁用区间在多轮启用之后，进程内存还包含其他模块和运行库保留的分配。该测试没有测量整个应用按前台和后台时长加权的内存。
