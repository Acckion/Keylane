# Phase 2 — 应用启动器、搜索与快捷键

版本：0.6.0。状态：已实现并安装测试包，尚未全部实机验收。Phase 1 按用户确认通过，搜索回归修复纳入本阶段回归测试。

## 功能与实现

- ApplicationCatalog：范围可配置、应用路径去重、排除与恢复、本地化名称和英文别名、中文完整拼音/首字母、英文词首字母。
- ApplicationDiscovery：递归 FSEvents 监听，合并事件、取消过期扫描并按 generation 丢弃过时结果；未创建目录监听最近父目录且过滤无关路径；空范围返回空列表。目录事件自动更新，无常驻全目录轮询。
- 应用运行状态由 NSWorkspace 启动/退出通知更新；结果图标有运行指示。启动失败保留错误并刷新目录。
- 搜索按匹配质量、收藏、调用频次、名称与稳定路径排序；用户别名精确匹配提高优先级。记录仅限 Keylane 内调用，不采集全系统使用行为。
- 应用设置：范围增删、应用筛选、别名、收藏、排除恢复、独立应用快捷键。应用列表使用有界滚动区域，避免上百项拉长整个设置窗口。
- ShortcutManager：Carbon 全局快捷键；内部重复、保留编辑/窗口组合与系统占用检查；替换注册失败时保留旧绑定；录制期间暂停全局绑定，取消、离开应用或离开控件时恢复。标准菜单仍提供显示启动器与关闭设置窗口入口。
- 修饰键：双击左侧 Command/Option/Control/Shift；Caps Lock Hyperkey 事件 tap；均默认关闭，需要用户启用和授权。安全输入时暂停，退出/关闭移除监听，不写系统永久键位映射。
- 导航设置：方向键，以及 Control+J/K 或 Control+N/P；不拦截普通文字输入；候选词存在时交给输入法。
- 应用参数：独立输入页、参数拆分预览、引号和转义校验，使用 NSWorkspace.OpenConfiguration.arguments 启动新实例，不执行 Shell 展开。
- Finder 动作子菜单：进入、返回、搜索、Escape 分层返回及空搜索的左右导航。
- 登录启动：SMAppService.mainApp；界面显示真实状态、错误与系统批准入口，不默认打开。

- 用户评价原位展开动画“不错”，仅要求略快；时长已由0.28秒改为0.20秒，仍遵循减少动态效果。
