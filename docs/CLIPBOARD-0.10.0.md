# 剪贴板 0.10.0

> 历史记录，描述该开发版的实现与当时的验证结果。

状态：开发中；核心自动化与独立剪贴板验证通过，安装版人工交互验收待完成。

## 共享界面

剪贴板与文件搜索复用 `ResultDetailLayout` 左右分栏；列表沿用 `HighlightedResultText`，底栏使用 `SecondaryPageBadge`。主窗口直接呈现该二级页面，避免外层再次添加上下内边距。列表保留搜索栏及底栏滚动安全区，不复制另一套分栏容器。设置仍在独立设置窗口。

## 本轮能力

- SQLite 结构版本2，标准文本、RTF、HTML、图片和文件引用可保留同一次复制的多个项目及各格式。普通复制还原格式，动作菜单可选择纯文本复制或粘贴。
- 富文本与同文纯文本区分去重；来源、次数、置顶和搜索资料持久化。搜索按多个词共同匹配，包含OCR与来源。
- 刷新时保留未变化的预览，过时查询回调被丢弃；查询或详情加载中禁止复制旧选择。
- 系统拒绝读取时显示提示；默认关闭历史采集，跳过敏感、临时及回放标记与排除应用。
- v1数据库升级前用SQLite备份接口保存旧数据库及自有图片。设置显示备份数量；清理全部历史同时清理升级备份，清理未置顶历史保留备份。
- 文件只保存引用；复制前检查可用性，清理历史不删除原文件。

## 边界和待验收

- 真实目标应用的自动粘贴、辅助功能拒绝、系统剪贴板访问拒绝以及安装版键盘/中文输入法，仍需实机验收。
- 仅保存白名单标准格式，不支持应用私有对象、延迟文件承诺或任意扩展类型；HTML和富文本预览为文字投影，复制保留原数据，不运行HTML内容。
- 文件引用保存位置而非副本。图片预览缓存丢失可回退到快照；文件已移走时会提示失败。
- 升级备份仍可能含旧历史；备份数量与清理规则在设置中披露。本地存储未加密，无云同步。
- Phase 3不因此全部完成；便笺、快捷链接、片段和补充检索继续延期。
