# 窗口管理

从主搜索选择左半屏、右半屏、上半屏、下半屏、最大化窗口、居中窗口、移到下一台显示器或恢复窗口位置和大小。每条命令可在「设置 → 窗口管理」中配置别名和快捷键。

命令调整启动器打开前所用应用的聚焦窗口。直接使用全局快捷键时，使用当前前台应用的窗口。首次使用需在 macOS 的「隐私与安全性 → 辅助功能」中允许 Keylane。

布局使用当前显示器的可用区域，避开菜单栏和程序坞。跨屏按系统显示器顺序循环，尽量保留窗口的相对位置与大小。窗口大于目标显示器时会尝试缩小。恢复命令保留每个窗口最近一次成功调整前的位置和大小，仅在本次运行中有效。已保存的位置和大小仍处于显示器可用区域内时，会原样恢复，包括横跨多个显示器的窗口。显示器断开或排列变化后，窗口会在需要时调整到当前可用区域内。

全屏窗口需先退出全屏。窗口拒绝调整或应用限制了最小尺寸时，Keylane 会报告失败，并尝试恢复原布局。

布局计算有自动化覆盖。已用独立 AppKit 测试窗口通过辅助功能执行左半屏、恢复和重复恢复检查。常用应用、不同排列的实体显示器和应用尺寸约束待实机验收。
