# 窗口管理

在「设置 → 窗口管理」启用功能并授予辅助功能权限。窗口操作面向打开启动器前的聚焦窗口。运行全局快捷键时使用当前前台应用的窗口。各命令可独立设置别名、快捷键和启用状态。

- **分屏与调整**。主搜索提供半屏、三分之一、四分之一、六分之一、靠边移动、最大化宽度或高度、按坐标移动或调整尺寸、全屏与最小化。窗口间距和屏幕边距各自可调。重复半屏命令可循环比例或显示器。跨屏命令可设置是否循环与保持宽高比。
- **网格与恢复**。使用「切换窗口网格」，在显示器上拖选区域后应用窗口间距和屏幕边距。焦点窗口改变时取消该操作。恢复命令记录每个窗口最近一次成功调整前的位置和大小。显示器断开后会在可用区域内恢复。
- **自定义命令与布局**。自定义命令可使用点或百分比指定宽、高、停靠位置及偏移。布局每台显示器最多容纳八个窗口，可指定应用、匹配窗口标题、打开 URL、文件、快捷链接或传递启动参数。保存当前布局后可先编辑再保存。其他窗口可保留、最小化或通过应用自己的关闭操作关闭。导入和导出使用 Keylane 的版本化 JSON。
- **快捷键与空间**。快捷键预设仅替换对应窗口命令的绑定。替换空间快捷键时，Keylane 在模块启用期间接管 Mission Control 当前的左右空间按键。停用模块或恢复系统快捷键后，按键继续由系统处理。空间动作会核对切换结果与窗口归属。拒绝移动时会尝试系统标题栏拖动和 Mission Control 快捷键。

窗口拒绝调整或应用限制了尺寸时，Keylane 会报告失败，并尝试恢复该窗口原来的位置与大小。应用全屏时可以切换全屏状态，其他几何操作需先退出全屏。

## 验证

自动化覆盖分屏边界、两类间距、靠边居中、跨屏和恢复、混合尺寸单位与布局存档。独立 AppKit 测试窗口通过辅助功能实测了半屏、屏幕边距、比例循环、恢复和指定尺寸。多台实体显示器、台前调度、应用尺寸约束与不同 macOS 版本的 Spaces 行为需分别实机验收。
