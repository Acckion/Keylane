# 列表文件拖出复制

维护：2026-11-25，功能分支 `feat/list-file-drag`，待合并。跟踪 FILE-02-a，涉及 FILE-02、CLIP-01、EXTRA-02。

主搜索和文件搜索中的文件、文件夹，剪贴板的文件组与图片缓存文件，以及下载列表均通过共用 `ResultListButton` 接入原生拖拽。拖出后只提供复制操作，不移动源文件；剪贴板文件组一起拖出。纯文字记录保持原行为。

普通点击沿用原动作。移动至少 5 点才准备拖拽，开始拖动后不再触发点击。异步准备在松手、行替换或销毁后失效；原生拖拽开始后独立持有文件授权和源视图，直至系统会话结束。拖拽不读文件正文，不申请额外目录授权；文件失效或不可读时不启动会话。

隔离验证入口：`scripts/verify-result-file-drag.sh` 检查文件/目录载荷、访问对象生命周期、普通点击、手势阈值及取消；文件搜索、剪贴板、下载原有验证脚本补查各控制器的载荷准备和停用边界。所有数据均为临时合成文件。

本轮验证：451 项 Swift 测试、30 项发行脚本测试、版本检查、Debug/Release 构建、原生手势隔离检查、文件搜索、剪贴板及下载集成检查通过。下载与剪贴板系统服务检查须在具有系统服务访问权限的环境运行；受限环境的通知超时不是通过证据。使用本机 Apple Development 身份生成临时 DMG，并通过签名、内容清单、架构和元数据校验；没有安装或替换现有应用。

安装版实机待验收：从各入口拖到 Finder 后核对副本和源文件；剪贴板多文件、文件夹、图片；取消与拒绝接收；Launcher 隐藏时会话完成；已授权外部目录与权限撤销。当前桌面正在运行其他应用的全屏演示，因此未继续桌面输入，不将隔离结果描述为真实 Finder 拖放通过。
