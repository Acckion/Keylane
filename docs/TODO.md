# 后续待办与开发优先级

## 当前执行顺序（2026-11-11用户确认）

本清单取代旧大阶段中的开发先后顺序；既有实现、数据与验收记录保留。**先把基础体验做好，再开发进阶功能。** 同档模块可按依赖和验收成本调整次序，但不得把AI或扩展兼容提前到基础体验之前。

| 优先级 | 范围 | 约束 |
|---|---|---|
| P0 基础收尾与基础设施 | 已有应用搜索、文件搜索、剪贴板的稳定性和统一界面；可复用的菜单栏展示能力 | 基础错误先修；菜单栏设施先于日历、Focus及未来扩展的菜单栏功能 |
| P1 基础功能 | Apple Shortcuts、Calculator、Calendar、Contacts、Dictionary、Emoji & Symbols、Navigation、Screenshots、Script Commands、System Actions、System Settings、应用自身工具与设置入口 | 每项单独交付与实机验收；系统动作的具体命令集在开发该项时确定 |
| P2 后续实用功能 | Quicklink、Focus、Apple备忘录集成、Snippets、Window Management | 均先于AI等进阶功能；窗口管理在Navigation基础能力后展开；Notes先研究集成方案 |
| P3 进阶功能 | AI、Browser上下文、Developer/扩展开发、Dictation、MCP、Translator、扩展兼容 | 暂缓；进阶功能之间的先后顺序后续决定，不为这些功能提前增加产品入口 |
| 不纳入当前范围 | Teams | 暂不考虑，不当作必需交付项 |
| 明确不做 | Typing Practice | 从开发范围排除 |

## 分批实施与阶段出口

以下是建议落地批次，模块归档优先级以上表为准。无未经调查的完工日期。

### A：基础收尾

- [ ] 应用、文件、剪贴板共用列表、预览、信息和筛选组件，修复发现的实际问题；保留中文输入和键盘路径回归。
- [ ] 核对已有模块的待验收项，不把“用户说已有实现”改写成“全部实机通过”。
- 出口：已有主要日常路径可稳定使用，未实测项有记录，不以加入大量新模块替代修复。

### B：菜单栏基础设施（已实现并接入日历）

- [x] 共用原生注册、更新、显隐、动作、子菜单和注销。Keylane主菜单与日历共用同一管理器。
- [x] 在设置中管理可见条目。原生集成测试覆盖重复注册、50次开关、动作和模块关闭清理。
- [x] 日历在后台读取系统资料，菜单展示当前结果。支持未授权、加载、空结果和已连接状态。
- [x] 安装版经用户授权后读取真实日程，菜单栏展示经用户截图确认。详细边界见[验收记录](MENU-BAR-CALENDAR.md)。

### C：直接检索与命令入口

- [x] Apple Shortcuts 首版：发现、搜索、按标识运行、别名、热键与启用状态。实机验证发现指令、缺失指令反馈和启动后自动加载原始图标。真实指令执行与实体热键待验收。
- [x] Calculator 首版：主搜索计算与回车复制，支持全角运算符、括号、乘方、百分比、科学计数及常用函数。单位与汇率保留在下方分项待办。
- [x] Dictionary 首版：查询系统启用词库、显示并复制释义、空结果反馈。真实词典查询通过。
- [x] Emoji & Symbols 首版：复用 ResultGrid，支持中英文检索、分类、常用、键盘导航及复制或粘贴。目录、搜索、过滤和网格选择通过组件验证。跨应用粘贴待实机验收。
- [x] Settings、System Settings 首版：启动器已有 Keylane 设置入口。系统设置支持中英文搜索及直接打开对应页面，已验证目录链接和启动器跳转。系统版本与硬件差异见[验收记录](SYSTEM-SETTINGS.md)。
- 出口：不用鼠标也能发现、进入、执行与返回；别名和快捷键通过统一命令体系保存。

### D：本机资料与日常系统工具

- [x] Contacts 首版：授权、搜索、详情、字段复制、系统联系人入口及变更刷新。已验证生成联系人字段，实机授权状态见[验收记录](NATIVE-UTILITIES-0.12.0.md)。
- [x] Calendar首版：系统日历只读接入，支持日期切换、当天搜索、日历选择、系统应用入口与菜单栏摘要。实机确认真实日程读取和菜单展示；详细交互按验收记录继续核对。
- [x] Screenshots 首版：支持选定目录、按名称和日期搜索、OCR、缩略图、预览及文件操作。移动原文件到废纸篓前需确认。跨应用粘贴、分享与云盘行为的验收见[截图记录](SCREENSHOTS.md)。
- [x] Script Commands 首版：指定目录发现、参数和工作目录、输出、失败、取消与超时。扫描只读取文件信息。详见[脚本命令](SCRIPT-COMMANDS.md)。
- [x] Navigation 首版：窗口切换、菜单项搜索与执行。两窗口与嵌套菜单实机测试通过；多显示器、全屏和 Spaces 待验收。见[验证记录](NAVIGATION.md)。
- [x] 应用自身工具首版：设置导出、更新日志、GitHub 发布检查和实时相机预览。验证范围见[应用自身工具](APP-UTILITIES.md)。
- [x] System Actions 首版：锁屏、Mac 睡眠、显示器睡眠、切换静音、隐藏其他应用和恢复隐藏应用。实机验收范围见[系统操作](SYSTEM-ACTIONS.md)。
- 出口：逐模块交付可运行版本；涉及真实资料、系统权限或外部服务的能力都有对应验收结果。

### E：后续实用功能

- [ ] Quicklink：沿用下方既有分项任务。
- [x] Snippets 首版：创建、搜索、编辑、删除、复制、粘贴和可选缩写展开。见[文字片段](SNIPPETS.md)。
- [ ] Window Management：先定义窗口布局、跨屏和恢复规则，复用Navigation窗口能力，单独验收。
- [ ] Notes：先调查Apple备忘录集成与权限、搜索、打开及编辑的可行范围，再确定设计；不迁移或删除旧便笺。
- [ ] Focus：先定义计时、状态恢复和实际专注行为，菜单栏复用基础设施；不把一个计时器当作完整专注模式。
- 出口：各项有明确实现边界、正常/失败/取消用例和实际使用验证，再启动进阶功能队列。

### F：进阶队列

AI、Browser上下文、Developer、Dictation、MCP、Translator、扩展兼容随后再排细化计划。已有实验代码不删除，但本轮不继续扩展，不以编译成功或静态入口计为完成。原计划中的同步、双架构发行等长期事项保留在功能清单中；本次不因此提前，也不默认为取消。
