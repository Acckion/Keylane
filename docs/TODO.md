# 后续待办与开发优先级

## 当前执行顺序（2026-11-11用户确认）

本清单取代旧大阶段中的开发先后顺序；既有实现、数据与验收记录保留。**先把基础体验做好，再开发进阶功能。** 同档模块可按依赖和验收成本调整次序，但不得把AI或扩展兼容提前到基础体验之前。

| 优先级 | 范围 | 约束 |
|---|---|---|
| P0 基础收尾与基础设施 | 已有应用搜索、文件搜索、剪贴板的稳定性和统一界面；可复用的菜单栏展示能力 | 基础错误先修；菜单栏设施先于日历、Focus及未来扩展的菜单栏功能 |
| P1 基础功能 | Apple Shortcuts、Calculator、Calendar、Contacts、Dictionary、Emoji & Symbols、Navigation、Screenshots、Script Commands、System Actions、System Settings、应用自身工具与设置入口 | 每项单独交付与实机验收；系统动作的具体命令集在开发该项时确定 |
| P2 后续实用功能 | Quicklink、Focus、Apple备忘录集成、Snippets、Window Management | 均先于AI等进阶功能；窗口管理在Navigation基础能力后展开；Notes先研究集成方案 |
| P3 进阶功能 | AI、Browser上下文、Developer/扩展开发、Dictation、MCP、Translator、扩展兼容 | 暂缓；进阶功能之间的先后顺序后续决定，不为这些功能提前增加产品入口 |
| 不纳入当前范围 | Teams | 暂不考虑，不当作必需交付项 |
| 明确不做 | Typing Practice | 从开发范围排除 |

## 分批实施与阶段出口

以下是建议落地批次，模块归档优先级以上表为准。无未经调查的完工日期。

### A：基础收尾

- [ ] 应用、文件、剪贴板共用列表、预览、信息和筛选组件，修复发现的实际问题；保留中文输入和键盘路径回归。
- [ ] 核对已有模块的待验收项，不把“用户说已有实现”改写成“全部实机通过”。
- 出口：已有主要日常路径可稳定使用，未实测项有记录，不以加入大量新模块替代修复。

### B：菜单栏基础设施（已实现并接入日历）

- [x] 共用原生注册、更新、显隐、动作、子菜单和注销。Keylane主菜单与日历共用同一管理器。
- [x] 在设置中管理可见条目。原生集成测试覆盖重复注册、50次开关、动作和模块关闭清理。
- [x] 日历在后台读取系统资料，菜单展示当前结果。支持未授权、加载、空结果和已连接状态。
- [x] 安装版经用户授权后读取真实日程，菜单栏展示经用户截图确认。详细边界见[验收记录](MENU-BAR-CALENDAR.md)。

### C：直接检索与命令入口

- [x] Apple Shortcuts 首版：发现、搜索、按标识运行、别名、热键与启用状态。实机验证发现指令、缺失指令反馈和启动后自动加载原始图标。真实指令执行与实体热键待验收。
- [x] Calculator 首版：主搜索计算与回车复制，支持全角运算符、括号、乘方、百分比、科学计数及常用函数。单位与汇率保留在下方分项待办。
- [x] Dictionary 首版：查询系统启用词库、显示并复制释义、空结果反馈。真实词典查询通过。
- [x] Emoji & Symbols 首版：复用 ResultGrid，支持中英文检索、分类、常用、键盘导航及复制或粘贴。目录、搜索、过滤和网格选择通过组件验证。跨应用粘贴待实机验收。
- [x] Settings、System Settings 首版：启动器已有 Keylane 设置入口。系统设置支持中英文搜索及直接打开对应页面，已验证目录链接和启动器跳转。系统版本与硬件差异见[验收记录](SYSTEM-SETTINGS.md)。
- 出口：不用鼠标也能发现、进入、执行与返回；别名和快捷键通过统一命令体系保存。

### D：本机资料与日常系统工具

- [x] Contacts 首版：授权、搜索、详情、字段复制、系统联系人入口及变更刷新。已验证生成联系人字段，实机授权状态见[验收记录](NATIVE-UTILITIES-0.12.0.md)。

## 应用程序与 Raycast macOS 的差异

对照基线为 Keylane `dev` 的 `374a714`，依据 [Raycast 应用程序](https://manual.raycast.com/applications)、[搜索](https://manual.raycast.com/search-bar)、[操作面板](https://manual.raycast.com/action-panel)、[自动退出](https://manual.raycast.com/auto-quit)和[系统命令](https://manual.raycast.com/system-commands)手册。以下条目沿用上文优先级，产品默认值和新增命令范围在开发时确认。

### 应用发现与搜索

- [ ] **Finder 替身和外置卷**。Keylane 已解析范围内的 `.app` 符号链接并按实际路径去重。补齐 Finder 替身和挂载事件处理，验收启动后挂载、卸载及重复引用时的结果刷新。
- [ ] **扫描深度**。Raycast 的可选深度搜索在新增目录中向下查找最多三层，Keylane 默认递归且没有固定层数。确认是否提供深度选项，验收嵌套目录、范围增删和大型目录的扫描表现。
- [ ] **应用名称与关键词**。保留本地化名称、英文名、Bundle 备用名称及用户别名，评估补充 Spotlight 关键词。用真实应用验证历史名称和本地化查询。
- [ ] **同名应用**。Keylane 按路径保留不同应用。给同名结果增加可辨识的信息，验收用户能从键盘选择并打开预期路径的应用。

### 键盘操作与设置

- [ ] **应用热键默认行为**。双方均支持始终激活和切换显示。Keylane 默认始终激活，Raycast 默认切换显示。确认产品默认值，并验收前台、后台及未启动三种状态。
- [ ] **应用动作快捷键**。现有 Finder 定位、显示简介、查看包内容、复制路径／名称／Bundle ID、隐藏、退出、强退和重启可从操作菜单执行。补齐常用动作的直接按键入口，检查与现有绑定冲突，并验证 Finder 自动化拒绝、强退确认和重启等待保存的路径。
- [ ] **操作面板内编辑别名和热键**。Keylane 当前从操作面板进入「命令设置」。增加直接编辑入口，复用已有保存和冲突检查。逐应用启用／隐藏和模块总开关已有。
- [ ] **收藏顺序**。已有收藏和重置单项搜索优先级。跟进手动调整收藏顺序，验收调整后顺序可持久化。

### 自动退出与卸载

- [ ] **自动退出设置**。Keylane 已支持逐应用设置固定时长。跟进全局默认时长、逐应用覆盖和操作面板直接开关。Raycast 的全局默认值是 3 分钟。
- [ ] **录制和播放保护**。评估录音／录像期间暂停自动退出，以及 Spotify、Apple Music 播放时保留对应应用。验收保护结束后恢复计时，并回归前后台切换、休眠和应用正常退出的保存提示。
- [ ] **卸载入口和验收**。Raycast 提供启动器内的应用列表，Keylane 的独立命令打开系统文件选择器，搜索结果也有卸载动作。评估启动器内列表，保留移入废纸篓前的确认及运行中应用限制。用安装版验证确认、取消、权限失败和结果刷新。见[现有实现与验证记录](APPLICATION-LIFECYCLE.md)。

### 相关系统命令

- [ ] 跟进「重启前台应用」，验收目标为唤起启动器前的应用，并覆盖保存提示与退出失败。
- [ ] 跟进「退出所有应用」及「退出除前台应用外的应用」，确认批量操作的警告、排除列表和部分失败反馈。
- 「隐藏其他应用」和「显示所有隐藏应用」已实现，见[系统操作记录](SYSTEM-ACTIONS.md)。

Raycast 手册将新建应用窗口、从应用结果打开最近文件、以管理员或其他用户运行、标记为游戏列为 Windows 专属功能。

## 文件搜索与 Raycast macOS 的差异

原对照基线为 Keylane `dev` 的 `374a714`。本轮从 `3827add` 核对并完善已有实现。Raycast 行为见[文件搜索手册](https://manual.raycast.com/file-search)和[操作面板手册](https://manual.raycast.com/action-panel#actions-by-item-type)。Keylane 已有主搜索混排、独立搜索页、类型筛选、Quick Look、文件详情、打开方式和系统分享。以下待办沿用现有优先级。

### 搜索入口与结果

- [x] **最近使用的文件**。独立搜索页空查询列出通过 Keylane 成功打开的最近文件，按打开顺序去重。显示时复核授权、忽略和失效路径。原生控制器测试覆盖排序、持久化和排除。
- [x] **路径跳转与目录浏览**。主搜索接受授权范围内的绝对路径和家目录路径，可定位 Finder。独立页可浏览目录、返回上级，并按名称、创建时间、修改时间排序，偏好持久化。临时目录覆盖中文、特殊字符、范围边界和排序。
- [x] **从主搜索跳到文件详情**。操作面板可用所选路径打开独立页并重置类型筛选。控制器测试覆盖精确文件、目录自身及失效路径。安装版的跳转焦点与键盘流程待验收。
- [ ] **主搜索覆盖**。Keylane 默认关闭主搜索的文件混排，开启后最多显示 10 条，独立页最多 200 条。验收混排开关、类型筛选和较长结果列表，并确认是否需要调整默认行为。

### 正文、范围与索引

- [ ] **正文覆盖与状态提示**。Raycast 使用 Spotlight 搜正文。Keylane 自建本地文本索引，支持指定 UTF-8 文本和 PDF，单文件上限为 2 MB、10 万字符。Spotlight 在关闭「使用忽略文件」时仅补充文件名。用常用文档、中文多关键词和 iCloud 占位文件验证边界，再决定是否扩展格式或增加正文覆盖提示。
- [ ] **范围授权与外置卷验收**。Keylane 需要用户选择可读目录才能启用，实际索引以授权范围为准。隐藏文件、外置卷索引、断开后保留结果和恢复默认已有实现。验收首次授权、范围变更、实际外置盘和网络共享的挂载、断开与重连。见[已有验证记录](PHASE-3-0.9.0.md)。
- [x] **从结果排除文件**。按精确路径排除项目和子项，可从反馈或设置撤销。控制器测试覆盖立即隐藏、持久化、重复撤销及恢复。规则保存在 Keylane 设置中。
- [x] **索引控制**。启动器和设置支持暂停、恢复与重建本地索引。暂停保留已有结果，恢复后补扫并刷新当前查询。临时文件测试覆盖暂停期间的已索引结果与恢复后出现的新文件。
