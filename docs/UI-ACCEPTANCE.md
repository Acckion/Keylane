# UI 复刻验收（发布门槛）

用户明确要求：UI 复刻是重要部分。功能实现不得代替视觉和交互验收。

## 基线与状态

参考：本机 SuperCmd 2.0.0 build 11。
当前 Keylane 0.3 已按用户提供的官方启动器截图实现第一轮布局还原：760×470 pt 无标题栏面板、28 pt 圆角、61 pt 搜索区、40 pt 列表行、原生应用图标、分组、键帽与底部操作胶囊。不是逐像素验收结论。

2026-11-10：官方应用 AX 结构已读到，确认搜索栏、建议分组、打开/操作按钮及列表。官方截图工具和开发版后续 UI 工具超时。用户提供的 1524×964 截图是本轮视觉依据。代码编译和原有 3 个测试通过；新版实际显示、焦点、快捷键、材质和动作菜单操作仍待实机验收。

## 每个模块的必交付项

1. 在相同屏幕缩放、窗口尺寸、系统外观、字体和数据条件下记录参考图和实现图。
2. 对照窗口宽高、圆角、顶部搜索区、列表行高、图标大小、文字基线、边距、分隔线和底部动作区域。
3. 对照 Frosted / Liquid Glass 的背景、透明度、色调、选中态和深浅色；同时检查“减少透明度”。
4. 记录键盘、鼠标、焦点、返回层级、参数输入、动作菜单、加载态、空态和错误态。
5. 测试拼音组合输入、滚动、窗口伸缩、多显示器和全屏空间。
6. 记录有意差异（独立名称和图标）及尚未还原项目。

## 验收页面

- 启动器：紧凑空闲、展开搜索、选中结果、参数输入、嵌套动作菜单、小组件。
- 设置：侧栏、分组、快捷键录制、主题和权限状态。
- 剪贴板：列表、详情、图片/文件预览、置顶与搜索。
- 便笺：列表、预览、编辑、格式工具栏、浮动窗口。
- 截图：选区、编辑器、标注工具、历史。
- AI：独立窗口、侧栏、消息、流式输出、工具活动和错误。
- 窗口切换：缩略图网格、选中边框、多屏适配。

只有功能和视觉交互都验证通过，模块才能标记为“实机通过”。
