# Python 缓存目录改用默认匹配规则

`__pycache__` 加入 `FileSearchOptions.defaultIgnores`，通过普通忽略规则跳过任意层级的同名目录，不再由 `FileIndexExclusionPolicy` 识别为自动排除目录。设置中可直接查看或移除此规则。

已有设置首次加载时补入规则，保留其他自定义模式，并从持久化自动排除列表移除 basename 为 `__pycache__` 的历史条目。迁移只补入一次；用户之后移除规则，重启也不会重新添加。此修改不删除磁盘目录或文件。

验证范围：

- `FileIndexExclusionPolicyTests`：默认匹配、目录内事件忽略、移除规则后重新允许事件、普通名称不误匹配；4 项通过。
- `FileIndexTests`：索引、通配规则和继承忽略规则等 6 项通过。
- 应用随 Swift 测试完整编译通过；版本检查及发布 Python 测试 27 项通过。
- `Tests/Integration/files-main.swift` 新增隔离偏好设置迁移与临时目录索引检查。当前基线的 `scripts/verify-files.sh` 缺少 AI 文件工具来源依赖，直接运行无法编译；本轮使用同样的编译步骤额外传入 `AIToolRuntime.swift`、`AIChatProject.swift` 和 `AIFileToolProvider.swift` 进行验证，不修改脚本。专项及完整文件控制器回归均通过，覆盖迁移、规则删除后索引、正文搜索、暂停恢复、文件事件、离线目录保留与移除等场景。可设置 `KEYLANE_VERIFY_PYCACHE_ONLY=1` 只运行缓存专项。

本轮未安装到 /Applications，未操作用户的索引或搜索设置。

## 暂停索引下的历史结果过滤

本地索引可能仍保存以前手动恢复过的缓存后代。结果合并现在对本地和系统来源统一使用当前路径祖先规则：启用 `__pycache__` 或用户自定义父目录模式后，即使索引暂停，也不会发布命中的历史结果。路径检查不要求文件在线，不删除保存的索引行；并支持配置范围的解析路径。

`Tests/Integration/file-search-paused-migration.swift` 使用独立临时目录和 UUID 偏好域，先实际索引已恢复的缓存，再暂停、迁移、重启并进行普通查询。修复前复现缓存及自定义排除目录后代泄漏；修复后仅返回允许的文件，且索引保持暂停、行数不变。移除缓存规则后，暂停时能读回已有条目，再次重启也保持移除结果。另有单元测试覆盖不存在的文件、配置范围的符号链接解析及目录边界。此回归不调用恢复索引或强制重建，也不访问用户真实索引、文件或安装版。

合成控制器编译方法沿用前述步骤，将 `Tests/Integration/file-search-paused-migration.swift` 复制为临时 `main.swift`，与生产 `FileSearchController.swift`、三个 AI 文件工具依赖及当前 KeylaneCore 一同编译运行。

此次边界修复验证：11 项索引与路径规则单元测试通过（应用编译通过）；暂停迁移的独立控制器回归通过；原有缓存专项及完整临时目录文件控制器回归通过，包括离线条目保留与移除。所有文件及偏好域均为合成测试数据，未安装、合并或发布。

## 排除检查先于候选上限

仅在发布时过滤历史结果，会让较新的排除条目占满 SQL 的 2000 候选或本地排序的前 200。现在查询通过临时 SQLite 路径判定函数，在 `WHERE` 阶段执行忽略规则及宿主传入的祖先路径策略，再进入原有候选和排序上限。常规页面和独立 AI 文件名查询共用该检查；仍保留 SQL 2000 候选、最多 200 个返回结果、原有相关性排序及取消检查，不扩大无界结果集。函数与策略仅存活于本次串行查询，完成或取消后清理。

独立索引接口仍按存储的 root 归属和限定路径授权，不要求二者字面路径相同；宿主传入的策略保留范围别名、手动恢复目录、忽略文件及离线保存结果的行为。发布阶段原有复查继续保留。

合成回归在暂停索引中分别放入 240 和 2400 个较新的缓存或自定义排除目录后代，均能返回更旧的合法结果且顺序正确，索引始终暂停、行数保留。单元测试另覆盖 200 返回上限、较小 limit、短名称查询、相关性、取消后再次查询、恢复目录策略和独立接口路径别名；15 项相关测试通过，应用编译通过。暂停迁移及大候选控制器回归通过。均仅访问 UUID 偏好域及临时索引／文件，未访问真实用户索引，未安装、合并或发布。
