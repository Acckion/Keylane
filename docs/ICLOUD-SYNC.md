# iCloud Drive 同步

首版使用用户主动选择的 iCloud Drive 文件夹。每台 Mac 选择同一文件夹，在「设置 → iCloud 同步」选择内容，然后打开右上角总开关。无需 Keylane 账号或 CloudKit 容器。总开关默认关闭；剪贴板分类另行选择，默认关闭。

## 内容与边界

- 通用偏好：外观、界面尺寸、窗口模式、位置、导航、返回行为、页面导航键、根搜索敏感度。
- 命令：快捷键、别名、收藏和收藏顺序，按命令分别合并。系统保留／重复快捷键不会静默覆盖；显示失败状态后可调整重试。
- 快捷链接与文字片段：按稳定 ID 合并；不执行收到的链接或片段。
- 窗口布局：按布局 ID 合并；显示器序号与文件引用仍可能需要在另一台 Mac 调整。
- 扩展偏好：当前已登记的剪贴板粘贴／显示／顺序选项、Emoji 列数／肤色／主操作、截图列数。采集、权限、目录授权及后台服务开关不跟随其他设备启用。
- AI 聊天：当前 dev 数据模型中保存的正文、模型引用、标题、置顶和归档状态。API 密钥、登录令牌与提供方凭据不在此范围。后续聊天附件模型需要独立登记其同步实现。
- 剪贴板：文字、受支持的富文本、图片、OCR 和置顶状态；文件仅同步路径引用，不上传原文件、访问书签或系统通用剪贴板临时文件。路径在另一台 Mac 不存在时不能打开。包含混合嵌入文件格式、无法安全减少为文件引用的记录暂不上传。
- 原便笺已被 Apple 备忘录替换，Apple 备忘录通过自身 iCloud 设置同步，不重复导出。

不包括截图文件、索引、搜索历史、脚本正文、密码、Keychain、系统授权、自动启动系统注册或本机目录授权。同步文件可被拥有共享目录访问权限的人读取；未另加 Keylane 密码加密。Apple iCloud 的传输／账户保护不应被描述为 Keylane 自行实现的端到端加密。

## 合并、删除和关闭

每台设备持有自己的清单文件，不同设备不写同一清单。条目使用逻辑时钟与设备 ID 确定冲突顺序，不依赖各台 Mac 的系统时间一致。新设备对已有同 ID 云端条目优先恢复云端值；本机独有内容合并上传。覆盖前将本机旧内容保存到 `Application Support/Keylane/Sync/<folder-id>/Recovery`。

手动删除产生持久删除标记。剪贴板自动过期或容量淘汰只影响本机，不产生跨设备删除。关闭总开关或单个类别暂停相应工作，不清空本机或其他设备的数据。开关撤销后不再接纳新的同步工作，已经进入模块写入边界的单次操作可能完成。

本地 journal、逐条待处理意图与清单之间支持中断恢复。每批仅写入少量整体检查点，避免每导入一条历史就重写整份 journal；未变化的清单不重复发布，避免元数据通知产生自触发同步循环。模块成功应用后才确认新版本；异常退出后识别已经应用的内容，不把云端导入误报成本机新编辑。存在失败意图的类别可暂停，不阻塞其他类别。

## 生命周期与性能

同步协调运行在专用 utility 队列。数据库只在本机，远端目录仅存独立内容对象和清单，文件读写使用 NSFileCoordinator。内容对象按 SHA-256 命名和验证。未下载的 iCloud 对象请求下载后稍后重试，不按空文件或删除处理。

本机修改合并防抖；NSMetadataQuery 仅查询用户所选同步文件夹，发现尚未下载的远端清单，并在变化时触发同步；一分钟兜底检查。关闭时停止查询、释放目录访问并取消同步定时器。剪贴板只枚举轻量元数据，图片与富文本按变化读取，避免每轮重新编码整个资料库。单次只保留一个大正文，不持有整份图片历史。协议限制：单对象96 MiB（包含富文本／图片的编码开销）、单清单16 MiB／50,000条、至多128清单文件／合计100,000清单条目；超限报错而非截断。

恢复副本、删除标记及云端旧内容对象首版不自动清理，避免离线设备复活已删除数据。清理与设备撤销尚无界面；退出某台设备请关闭其总开关，删除清单文件不等于撤销该 Mac 的 iCloud 文件访问权限。设备列表表示清单最近更新，不表示该设备当前在线或已下载完成。

## 验证

自动化只使用临时目录和新建的剪贴板 SQLite 资料库，不读取系统通用剪贴板，不启动用户已有聊天或采集任务。测试覆盖双设备合并／修改／删除、首次恢复、离线冲突恢复副本、中断重试、类别关闭、取消、校验与符号链接拒绝、富文本／图片／引用、超过界面500条上限的历史及空闲轮次零图片正文读取。

macOS 文件协调服务需要在允许连接系统服务的测试环境运行；受限运行中的协调失败不能被当作 iCloud 服务验证。两个本地资料库通过同一目录的测试，不等于两台真实 Mac 完成 iCloud 上传／下载。后者需要两台 Mac 实机验收，启用真实资料同步由用户在设置中操作。
