# 0.10.1 剪贴板快捷键首次唤起修复

> 历史记录，描述该开发版的实现与当时的验证结果。

紧凑模式下，剪贴板和文件搜索快捷键先设置页面，再调用 revealLauncher；隐藏窗口的 revealLauncher 又调用 show，触发主菜单专用的页面重置。因此首次按键只能打开主菜单，窗口已显示时第二次才进入目标页面。

将只负责显示当前页面的 presentLauncher 从 show 提取。主菜单快捷键保持显隐及紧凑模式重置；直接打开页面的 revealLauncher 不再调用会重置页面的 show。未更改快捷键绑定或系统权限。

验证：31项测试通过；取自实际源文件的 show/revealLauncher/presentLauncher 方法在隔离窗口替身中通过：紧凑/完整模式、首次剪贴板/文件页、重复打开保持页面，以及主菜单重置/显隐。该检查不等同于真实全局按键和安装版视觉验收，后者待用户确认。
