# AI Chat 录屏与界面对照

依据用户提供的 3 分 55 秒录屏及后续两张窗口截图核对。只参考可见交互，不复制 Raycast 代码、图标、商标或订阅权益。录屏每 2 秒抽帧复查，共 118 帧；菜单、模型弹层、右侧设置和项目创建均单独核对。

## 基础聊天本轮对齐

| 入口 | 演示行为 | Keylane 对应实现与验收点 |
| --- | --- | --- |
| 窗口与侧栏 | 三栏，可折叠历史与会话设置 | 保留原生 split view；侧栏分组和会话行共用组件，统一 13 pt 常规字重、灰色图标、34 pt 会话行；取消原生 List 自动染蓝和大幅分组留白 |
| 顶部按钮 | 搜索独立圆形；操作与设置共用一组 | 搜索与后两项之间使用原生工具栏固定间距，不再将三项合为一组 |
| 输入区 | 加号、自动增高输入、发送或停止 | 34 pt 点击区域及 22 pt 加号；原生 NSTextView 管理光标、换行、滚动与 IME；最大高度 150 pt |
| 加号菜单 | 上下文选择与搜索 | 共用可搜索菜单，包含文件、剪贴板历史与当前文字、截图文字、选中文字、日历日程；选定内容显示为可移除标签 |
| @ | 在光标处触发匹配菜单 | 基础上下文来源共用补全菜单；只识别单词边界，排除邮箱、URL、选区和中文组词；保留光标后文字 |
| / | 命令与模型列表 | /usage 复用订阅用量面板；AI 命令、项目与已配置模型可搜索。没有可靠速度/能力信息时不伪造模型档位 |
| 菜单键盘 | 上下键、回车、Esc | 补全优先处理菜单操作；Shift Return 换行；依据发送偏好处理 Return；⌘ Return 发送。悬停不主动滚动列表 |
| 消息 | 复制、分支、重新生成 | 复用消息动作组件；编辑与重试创建分支保留原记录。附件与完整轮次进入后续请求，重试、分支和恢复保留附件 |
| 历史右键 | 复制、分支、置顶、重命名、归档、删除 | 全部提供；异步复制不覆盖用户后来更改的系统剪贴板；删除保留原有确认 |
| 操作面板 | 搜索并执行会话动作 | 编辑最新问题、重试、分支、复制整段或最新回复、导出、查找、聊天设置、用量、全宽、置顶/归档/重命名和 AI 设置 |
| 右侧设置 | 标题、模型、附加指令 | 继续共用模型菜单；更换已有会话模型需要确认新建；标题和指令合并保存；不显示无实际作用的设置 |
| 草稿生命周期 | 切换、关闭、发送时状态一致 | 共用 clear() 同时重置文字、光标、补全、附件与草稿代次；旧 OCR 或选择结果不能进入另一段草稿 |

## 项目与基础入口

用户本轮确认项目直接实现，工具、技能和语音先提供基础或占位：

- 项目支持创建、编辑名称/图标/指令、默认附件目录、侧栏折叠、新对话、移动会话、斜杠菜单选择和移除。移除项目只解除归组，聊天记录与置顶/归档状态保留。
- 项目指令与会话附加指令组合，应用于后续请求；分支保留项目；移动正在生成的会话会先停止请求。项目不会自动读取其他聊天或目录内容。
- 项目目录保留用户通过选择面板授予的书签，只用于默认附件目录。工具工作目录与跨会话记忆在运行层接入前不显示可用开关。
- @ 菜单、右侧设置和输入框的工具/技能/语音入口明确标注“尚未接入”，只说明状态；不执行系统命令、不加载本地技能、不启用麦克风、不请求额外权限。
- reasoning summary、工具调用事件、权限策略、真实语音及窗口/元素/区域/整屏感知留待运行层接入。当前“截图文字”明确使用用户选择的图片进行本地 OCR，不冒充视觉模型或屏幕感知。
- 不复刻 Raycast 订阅档位和专有自动选模，不捏造速度/智力评分、额度和模型推理内容。

项目数据使用现有私有 SQLite 的新增表与可空元数据列，旧记录不重写。安装前备份旧聊天库，再验证新版本能读取原记录。

## 验证

- `verify-ai-chat-input.sh` 在独立 AppKit 测试窗口验证真实输入组件的光标、补全、标记文字、键盘分派与焦点；不读取用户历史，不发送模型请求。
- `verify-file-ai.sh` 验证 UTF-16 token 范围、Emoji、光标后文字、无效输入、上下文总大小、旧记录兼容及附件在历史/重试/分支中的保留。
- 安装版仍需逐项核对侧栏、加号/@/斜杠菜单、工具栏分组、长输入、中文输入法和三栏缩放；只有截图或实际交互验证过的项目才记为实机通过。

侧栏和右侧设置按各自实际渲染字段订阅控制器，避免流式正文和输入草稿变化反复重建历史列表。常规密度和紧凑密度菜单共用 LauncherMenuRow，聊天操作与输入菜单不再分别维护行样式。
