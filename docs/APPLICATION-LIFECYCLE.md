# 应用程序模块

## 卸载应用

搜索「卸载应用程序」可在启动器内按名称或路径查找应用。也可从应用结果的操作面板进入。确认框会显示名称和路径。应用仍在运行时，Keylane 会提示先正常退出。

确认后仅将选中的应用程序包移到废纸篓，并刷新应用列表。应用的文档、偏好和支持文件会保留。系统应用、Keylane 自身、符号链接及嵌套在其他应用包中的应用会被排除。应用被移动、替换或系统拒绝操作时会显示失败原因。

## 自动退出

从应用结果的操作面板启用或关闭自动退出。「设置 → 应用程序」可设置全局默认时长，初始为 3 分钟。已启用的应用可跟随默认值或使用独立时长。已有固定时长会保留。新应用默认关闭。

应用切回前台、系统休眠或切换会话会重置计时。检测到活跃的麦克风输入或摄像头时，暂停所有自动退出。Spotify 和 Apple Music 活跃音频输出只保护对应播放器。保护结束后重新计算完整闲置时长。自动退出发出正常 macOS 退出请求，应用可以提示保存或取消。仅录制屏幕且没有麦克风或摄像头活动时，当前保护无法识别。
