# 应用程序模块

## 卸载应用

搜索「卸载应用程序」可在启动器内按名称或路径查找应用。也可从应用结果的操作面板进入。确认框会显示名称和路径。应用仍在运行时，Keylane 会提示先正常退出。

确认后仅将选中的应用程序包移到废纸篓，并刷新应用列表。应用的文档、偏好和支持文件会保留。系统应用、Keylane 自身、符号链接及嵌套在其他应用包中的应用会被排除。应用被移动、替换或系统拒绝操作时会显示失败原因。

## 自动退出

从应用结果的操作面板启用或关闭自动退出。「设置 → 应用程序」可设置全局默认时长，初始为 3 分钟。已启用的应用可跟随默认值或使用独立时长。已有固定时长会保留。新应用默认关闭。

应用切回前台、系统休眠或切换会话会重置计时。检测到活跃的麦克风输入或摄像头时，暂停所有自动退出。Spotify 和 Apple Music 活跃音频输出只保护对应播放器。保护结束后重新计算完整闲置时长。自动退出发出正常 macOS 退出请求，应用可以提示保存或取消。仅录制屏幕且没有麦克风或摄像头活动时，当前保护无法识别。

## 扫描范围刷新回归

本轮在合成应用目录中复现了符号链接根目录扫描为空、目录移走后未清除结果、同路径重建后未刷新。修复后，扫描解析根目录的符号链接，文件系统监听会在根目录变动后重新绑定到可用目录。使用 `bash scripts/verify-application-discovery.sh` 可复跑。

检查覆盖 Finder 替身和符号链接去重、目录内增删、替换链接目标、移走及重建扫描范围、切换范围后丢弃旧结果，以及停止后不再发布。合成同名应用用于验证路径和别名排名。Swift 测试另外核对系统设置的中、英、法、德名称与拼音查询。安装版键盘选择、实际启动应用及外置或网络卷待验收。

使用 `bash scripts/verify-application-favorites.sh` 复跑。测试使用临时应用包、独立偏好域和暂挂的全局热键注册，调用启动器实际使用的搜索、动作和保存逻辑。合成应用不启动。测试不触发 Finder 自动化或系统权限申请。
