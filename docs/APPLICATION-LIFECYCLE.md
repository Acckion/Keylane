# 应用卸载与自动退出

## 卸载应用

从启动器搜索「卸载应用程序」来选择应用，也可以在应用结果的操作菜单选择「卸载应用…」。确认框会显示应用名称和路径，选择「移到废纸篓」才会处理。应用仍在运行时需先正常退出。所选项目被移走、替换或 macOS 拒绝操作时，会显示失败原因。

仅移动所选应用程序包。应用的文档、偏好和支持文件会保留。系统应用、Keylane 自身、符号链接及其他应用包内部的应用无法通过此入口卸载。

## 自动退出

从应用结果或「设置 → 应用程序」的单个应用菜单选择「配置自动退出…」。每个应用默认关闭，可选择 5、10、15、30、60 或 120 分钟。也可搜索「管理自动退出」查看和关闭已配置的规则。

闲置以应用离开前台为准，应用回到前台会重置计时。休眠或切换会话会重置计时。关闭「应用程序」扩展会暂停自动退出。配置保存在本机，并以应用路径和 Bundle Identifier 匹配应用。

自动退出发出普通的 macOS 退出请求。应用可以提示保存或取消，同一次闲置期间只请求一次。

## 验证范围

独立 AppKit 测试应用验证了默认关闭、配置重读、到期前继续运行、到期后收到正常退出请求和关闭规则。实际应用的保存提示，以及卸载确认、取消和系统权限反馈待安装版验收。
