# 快捷链接

在主搜索输入「搜索快捷链接」打开列表，按名称、地址、标签或别名查找。按 ⌘P 打开标签筛选。置顶仅调整列表排序。「从主搜索隐藏」保留独立列表、设置和已配置的热键入口。选中条目后按 ⌘K，可以打开、编辑、复制为新链接、复制名称或链接、置顶、隐藏及删除。

「创建快捷链接」打开启动器内的表单，也可在「设置 → 快捷链接」添加和编辑。设置页提供创建、搜索、导入和导出命令的别名、热键及启用选项，并支持单独配置每个链接。

链接支持 HTTP、HTTPS 和单一收件人的 `mailto:` 地址。把参数放在网页链接的路径、查询或片段中，例如：

    https://example.com/search?q={关键词}
    https://example.com/{路径}?language={语言=zh-CN}

回车可在参数间移动，填写完成后交给系统打开。留空时使用模板里的默认值。返回、Esc 或隐藏启动器会取消本次输入。中文、空格和 URL 分隔符按参数值编码。

与文字片段共享的[动态占位符](SNIPPETS.md)支持 `{clipboard | trim}`、`{selection}` 和带选项的命名参数。占位符默认按 URL 参数值编码，使用 `raw` 可以保留原值。编辑时会转换能迁入新语法的旧模板，已有四参数模板沿用原有语义。

「导入快捷链接」与「导出快捷链接」使用 JSON 数组。每项包含 `name` 和 `link`，兼容 [Raycast 的基础导出字段](https://manual.raycast.com/quicklinks)。Keylane 的 JSON 还可保留标签、置顶、主搜索隐藏和旧参数语义。导入跳过名称和链接都相同的条目并报告数量。别名、热键、打开应用和图标不在交换范围内。

旧版单链接迁入集合后保留原命令 ID。原值留在旧偏好键中，可以在设置使用「恢复旧链接…」另存。迁移后的空集合重启后保持为空。

## 验证

Swift 测试覆盖标签匹配、排序、旧数据兼容、重复导入、JSON 往返、中文 URL 编码和无效地址。控制器验证使用独立偏好和模拟打开处理器，覆盖取消参数、保存、重载及损坏资料保护。安装版的浏览器跳转、热键、标签菜单及文件选择面板待实机验收。
