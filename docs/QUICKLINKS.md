# 快捷链接

在「设置 → 快捷链接」添加、编辑、搜索或删除链接。每条链接可在本页或「设置 → 快捷键」设置别名、热键和启用状态。主搜索可以直接查找并执行已启用的链接。

链接支持 HTTP 和 HTTPS。把参数放在路径、查询或片段中，例如：

    https://www.google.com/search?q={关键词}
    https://example.com/{路径}?language={语言=zh-CN}

回车可在参数间移动，填写完成后打开默认浏览器。留空时使用模板里的默认值。返回、Esc 或隐藏启动器会取消本次输入。输入中的中文、空格和 URL 分隔符会按参数值编码。

也可以使用与文字片段共享的[动态占位符](SNIPPETS.md)，例如 `{clipboard | trim}`、`{selection}` 或 `{argument name="语言" options="zh-CN, en-US" default="zh-CN"}`。占位符默认按 URL 参数值编码，使用 `raw` 可以保留原值。已保存的旧模板沿用原有参数语义，打开编辑页时转换为显式的命名参数。

旧版单链接会迁入集合，保留原命令 ID。原值留在旧偏好键中。修改或删除迁入的链接后，可以从设置使用「恢复旧链接…」将旧值另存为一条新链接。已迁移的空集合重启后保持为空。

## 验证

自动化测试覆盖中文和特殊字符编码、参数默认值、无效地址、重复迁移、旧值保留和损坏数据保护。安装版的浏览器跳转、参数页键盘交互和实体热键待实机验收。
