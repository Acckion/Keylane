# Keylane 自身工具

从主搜索运行「导出 Keylane 设置」「查看 Keylane 更新日志」「检查 Keylane 更新」或「显示相机」。命令通过内置模块登记，设置中可管理启用状态、别名和快捷键。

- 「导出 Keylane 设置」也可从「设置 → 高级」执行。导出的 JSON 包含已保存的启动器、外观和键盘行为偏好。密钥、用户历史、快捷键映射、自由文本、文件路径和系统授权资料均不在导出范围内。
- 更新日志打开 GitHub Releases。检查更新在用户主动执行时读取公开发行列表和标签对应的版本清单，按版本和构建号比较，显示正式版或预发行版并提供发布页面入口。安装由用户在发布页面操作。
- 相机预览使用系统默认视频设备。首次打开时请求相机权限；关闭窗口后停止采集。预览不使用麦克风，不写入媒体文件。可在「设置 → 权限」查看相机权限状态。

## 验证

- 设置导出测试使用独立偏好域，验证允许的偏好键和值及敏感数据排除。
- 通过实际 GitHub 发布接口读取了 v1.0.0-alpha.2 的版本清单，构建号为 24。
- 相机授权、实际画面以及关闭后的设备释放待在安装版验证。
