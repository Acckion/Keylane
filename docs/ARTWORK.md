# 功能与命令图标

本批按 2026-11-21 的设置和命令目录补齐资源，共新增 60 张、重绘 5 张 PNG。图片保存在 `Resources/ModuleArtwork/`，映射由 `Sources/Keylane/ModuleArtwork.swift` 统一维护。设置侧栏、页面标题、命令搜索和通用命令设置行共用映射。

## 设置侧栏

- AI 归入内置扩展，排列在该分组首位。
- 下载使用文件夹与向下箭头。
- 联系人使用蓝色背景的联系人卡片。
- 截图使用屏幕图片与选区角标。
- 日历使用完整日历页、装订环和日期数字。
- 计算器使用数字显示及四个带符号的按键。
- 快捷指令从本机 Shortcuts.app 读取原生图标，统一显示边距。
- Keylane 工具从应用包读取自身图标，开发运行时可从已注册的应用读取。

## 命令资源

命令图标使用用途明确的主体，按润色、摘要、历史、样式、词汇、搜索、创建、导入、导出及系统动作分别映射。相同操作可跨模块复用对应图案，例如备忘录和剪贴板的摘要使用同一摘要资源。

动态创建的快捷链接继续沿用链接资源，自定义 AI 命令沿用 AI 命令资源。已有系统资源和品牌图标由本机应用提供。

## Raycast AI 命令参考资源

根据官方手册准备下列图案，已存在的 Keylane 命令接入相应映射，其余保留为后续命令资源。

| 用途 | 图案 |
| --- | --- |
| 润色 | 编辑笔与星芒 |
| 摘要 | 文本归纳 |
| 拼写和语法纠错 | 文档与勾选 |
| 通俗解释 | 灯泡与文字 |
| 专业语气 | 文档与领带 |
| 友好语气 | 微笑对话气泡 |
| 代码检查 | 代码括号与放大镜 |
| 网页摘要 | 网页与摘要行 |
| 网页问答 | 网页与问号气泡 |

参考 [Raycast AI Commands](https://manual.raycast.com/ai/ai-commands)。

## 预备菜单动作资源

剪贴板暂停与清空另有预备资源。当前剪贴板命令中的顺序粘贴、重置粘贴和 AI 操作已接入各自图案，已有操作菜单沿用菜单组件的显示方式。

## 维护与验证

增加命令时，核对主搜索、设置命令行和模块入口的图片。新增 PNG 随打包脚本整体复制，资源引用回归测试检查设置与命令映射指向的文件存在。使用系统原生图标的别名单独在加载器中处理。

本批的逐张预览、构建、测试和打包检查结果记录在关联 PR。真实安装版界面继续按用户反馈验收。
