# 内置模块迁移

## 当前集成范围

架构工作树基于已提交的 dev（d351267）。该基线的应用、系统入口、快捷链接、便笺、剪贴板、文件搜索、文件 AI 和计算器已经登记。主工作区中的共享详情、日历、窗口与菜单导航、联系人、词典、Emoji 和 Apple 快捷指令仍在并行开发。整体迁移在这些功能进入 dev 后继续，全部验收后合成一个架构 PR。

## 接入契约

- 在应用组合点注册 LauncherModule。命令声明和运行时分开。目录校验只看值，检测模块、命令、页面、设置页重复以及无效路由。动态结果提供者声明互不重叠的 ID 命名空间。
- 根搜索的输入只含当前页面、查询和排名偏好。模块通过 searchUpdates 声明会改变候选的状态，候选刷新后由 LauncherCommandSearch 缓存排名。已有文件查询代次仍由 FileSearchController 维护。
- 命令执行按 CommandID 查找并检查实时可用性。搜索、全局热键和应用菜单走同一路径，来源保留应用热键激活和文件 AI 唤起的既有行为。应用路径仍是历史别名、收藏和使用次数的键，执行 ID 使用 app: 前缀。现有持久化格式不变。
- 页面声明内容、搜索提示、查询、离开、键盘操作和动作菜单。窗口只转发当前页的更新。剪贴板离开后取消展示查询和预览，采集服务继续按用户现有设置运行。文件页面继续复用宿主的共享列表和详情。
- 现有设置导航从模块登记读取内容工厂和搜索锚点。服务与命令目录分开启动，注册时不构建页面、不执行命令、不启动模块定时器。

## 后续集成门槛

在并行功能各自合入 dev 后更新工作树，再迁移新增模块。保留原命令 ID、设置锚点、已授权控制器和用户偏好。Apple 快捷指令注册 shortcut: 命名空间；导航页保留前一个应用的快照及退出时取消操作；日历把既有 MenuBarRegistry 注册和定时刷新接入模块生命周期；联系人、词典和 Emoji 只向活跃页面发布状态。按最终界面所需接入日期导航、分类筛选和横向键盘动作。共享列表和详情按最终集成版复验。

当前验证覆盖注册不激活服务、命令来源一致、禁用命令拒绝执行、缓存失效、重复 ID、失效路由、关闭剪贴板页面后继续采集、文件事件及既有评分规则。最终版的输入法、焦点、滚动、菜单栏、Quick Look 和持续 CPU / 内存尚待实机验收。
