# 紧凑启动器与横向切换

紧凑主搜索的固定顺序为主搜索、文件、文字片段、剪贴板。后三项来自同一份 `CompactLauncherShortcut` 声明；禁用的命令不能执行，也不会成为滑动目的地。空查询时显示搜索框和三个圆按钮，输入时先合并按钮再展开结果；文字编辑器留在玻璃合成层之外。

展开后的页面通过横向滚动切换。手指移动直接更新轻量的位移观察对象，窗口外框不移动；相邻内容间隔 10 点，松手后以速度相关的非线性曲线完成切换。短距离回弹、纵向滚动和系统减少动态效果分别处理。菜单、输入法组合和参数编辑期间不切换。

邻页使用只读预览，不提前激活另一个模块。文件预载和正式最近文件列表共享解析、权限和忽略规则；短期预载只供下一次滑动进入使用。剪贴板只通过已运行的存储服务读取预览。切换后保留预览直到当前页面完成加载，再交还给可交互页面。隐藏窗口会释放预览和位移状态。
