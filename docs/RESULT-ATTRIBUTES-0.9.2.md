# 0.9.2 结果行右侧属性

主搜索与文件搜索列表右侧默认显示条目属性：应用、命令、文件、计算结果。移除标题旁重复的“命令”标签，AI来源仍可保留简短说明。

按住Command时，前九个结果的属性临时替换为现有圆角方框样式的⌘1至⌘9；第十项之后仍显示属性。松开Command、隐藏窗口或离开焦点后恢复。固定右侧66点宽，避免切换时挤动内容。原有Command数字执行逻辑不变。

使用AppKit应用内flagsChanged观察，不增加全局事件监听、辅助功能或输入监控权限；显示窗口时同步当前修饰键，隐藏后移除观察器。

28项核心测试与构建通过。独立状态检查覆盖Command按下、组合键、松开和隐藏重置；尚未通过物理键盘和安装版截图完成视觉验收。

构建继续使用固定开发证书签名，数据及已有权限配置不清理。
