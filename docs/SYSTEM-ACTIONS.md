# 系统操作

在主搜索输入以下命令的中文或英文名称。别名、热键和启用状态可在「设置 → 系统」管理。

| 命令 | 行为 |
| --- | --- |
| 锁定屏幕（Lock Screen） | 通过 macOS 的 Control + Command + Q 锁定当前会话。发送快捷键需要辅助功能权限。 |
| 让 Mac 睡眠（Sleep Mac） | 请求 macOS 立即睡眠。 |
| 让显示器睡眠（Sleep Displays） | 请求 macOS 关闭显示器画面。 |
| 切换静音（Toggle Mute） | 切换默认音频输出设备的静音状态。设备缺少可写的全局静音属性时显示提示。 |
| 隐藏其他应用（Hide Other Apps） | 保留启动器唤起前的前台应用，隐藏其他普通应用。 |
| 显示所有隐藏应用（Unhide All Hidden Apps） | 恢复已隐藏的普通应用。 |

[Apple 的 Mac 键盘快捷键](https://support.apple.com/zh-cn/102650)

## 验证

- 在临时应用上验证了隐藏和恢复后的实际可见状态。
- 已读取本机默认输出设备及其静音属性。该验证未更改音频状态。

锁屏、Mac 睡眠、显示器睡眠及修改实际音频设备静音状态待实机验收。
