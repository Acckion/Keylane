# 系统操作

在启动器主搜索输入中文或英文命令名称。命令标题根据系统首选语言显示，设置 → 系统可以管理命令、别名和快捷键。

| 类别 | 命令 |
| --- | --- |
| 通知与控制中心 | 清除通知、切换蓝牙、切换台前调度、切换系统外观 |
| Finder 与磁盘 | 打开废纸篓、清空废纸篓、推出所有外部磁盘、切换隐藏文件显示 |
| 应用与桌面 | 隐藏其他应用、显示所有隐藏应用、退出所有应用、退出其他应用、重启前台应用、显示桌面、启动屏幕保护程序 |
| 会话与电源 | 锁定屏幕、注销、重启 Mac、关机、让 Mac 睡眠、让显示器睡眠 |
| 媒体与音频 | 播放或暂停、上一曲、下一曲、切换静音、提高音量、降低音量、设置音量、将音量设为 0%、25%、50%、75% 或 100% |

「设置音量」打开带有当前音量的滑块。使用 HDMI、数字输出等固定音量设备时，Keylane 会提示当前设备不支持调节。

「设置 → 权限」中可以启用系统快捷键、控制中心与通知、系统事件自动化以及 Finder 自动化。清空废纸篓使用 Finder 自动化，切换外观和注销、重启、关机使用系统事件自动化。启用需要 macOS 授权。清空废纸篓、注销、重启和关机执行前会要求确认。

蓝牙与台前调度使用 macOS 在控制中心提供的辅助功能控件。控件不可用时会显示提示。显示桌面使用 macOS 默认的 Fn-F11 快捷键，控制中心和通知中心分别通过 Fn-C 和 Fn-N 打开。

[Apple 的 Mac 键盘快捷键](https://support.apple.com/zh-cn/102650) · [Raycast 系统操作参考](https://manual.raycast.com/system-commands)

## 验收

- 在启动器用中文和英文搜索同一命令，检查标题随首选语言显示。取色、朗读、停止朗读和个人文件夹应各显示一种语言。
- 在设置关闭权限后确认相应命令不可执行。启用权限后，验证媒体快捷键、Finder 和控制中心的实际行为。
- 验证音量页可读出当前音量，提交后以 macOS 音量为准。使用固定音量设备时检查反馈。
- 注销、重启、关机、清空废纸篓、清除通知和推出磁盘需要在合适的设备和会话中实测。
