# 文字片段

从启动器运行「创建文字片段」填写标题和内容，可选填缩写。用「搜索文字片段」按标题、缩写或内容查找。回车将片段粘贴到上一个应用，目标不可用时可从剪贴板取得内容。操作菜单也可复制、编辑和删除片段。片段保存在本地 SQLite 资料库。

内容支持 {date} 和 {time}，会按系统地区格式在使用时替换。{cursor} 在缩写展开时定位光标。通过启动器复制或粘贴时会移除该标记。

## 缩写展开

在设置的「文字片段」页启用「展开缩写」，并在「权限」中允许辅助功能。输入完整缩写后按空格。缩写可使用最多 40 个可见 ASCII 字符，同一缩写只能分配给一个片段。

展开默认关闭，只在兼容辅助功能编辑接口的文本框中替换已确认的缩写。安全输入、密码字段、非 ASCII 输入源、焦点变化和其他无法确认的编辑状态会跳过。自动展开直接更新目标文本，剪贴板可继续使用原来的内容。
