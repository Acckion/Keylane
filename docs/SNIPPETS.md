# 文字片段

从启动器运行「创建文字片段」。左侧编辑正文和格式，右侧填写名称、图标、关键词及标签。用「搜索文字片段」按名称、关键词、正文或标签查找，也可以从右上角按标签筛选。操作菜单提供复制、粘贴、编辑、复制为新片段、置顶和删除。片段保存在本地 SQLite 资料库。

## 动态占位符

输入 `{`，或把插入点移到一对花括号内，即可在插入点附近选择占位符。支持方向键选择、回车插入和 Escape 关闭。可用占位符包括：

| 用途 | 写法 |
| --- | --- |
| 剪贴板文字和历史 | `{clipboard}`、`{clipboard offset=1}` |
| 引用片段 | `{snippet name="常用回复"}` |
| 插入后放置光标 | `{cursor}` |
| 日期、时间、星期 | `{date}`、`{time}`、`{datetime}`、`{day}` |
| 相对日期和自定义格式 | `{date format="yyyy-MM-dd" offset="+1M -2d"}`、`{time locale="en-US-u-hc-h23"}` |
| UUID 和计算器 | `{uuid}`、`{calculator expression="2 * 3"}`、`{calculator}` |
| 填写参数 | `{argument name="语气" options="简短, 正式" default="简短"}` |

支持 `uppercase`、`lowercase`、`trim`、`percent-encode`、`json-stringify`、`raw`，可用竖线依次组合。日期格式和地区只能指定其一。模板最多包含三个不同参数，同名参数复用一次输入。引用的片段可以含占位符，不能继续引用片段。读取旧剪贴板条目需要启用剪贴板历史。手动粘贴和自动展开会在目标应用支持定位时放置光标。

快捷链接和未来的 AI 命令共享解析器。快捷链接支持选中文字和 URL 编码。AI 模板通过调用方提供选中文字、上一条消息或浏览器标签页内容，浏览器格式及 CSS 选择器会传给该调用方。当前应用没有 AI 命令或浏览器扩展入口。

## 关键词展开

在设置的「文字片段」页启用「启用片段展开」，并允许辅助功能。新配置默认立即展开，已有配置沿用原来的保留分隔符行为。可选择保留或舍弃分隔符、在单词中匹配、优先于系统文本替换、调整注入延迟和响应时间、选择完成音效及排除应用。

安全输入、非 ASCII 键盘输入源、密码字段和无法确认的目标编辑状态会暂停自动展开。富文本自动展开需要读取并还原系统剪贴板。遇到无法安全保存的剪贴板项目或目标不支持富文本时，使用纯文本。删除警告默认开启，「搜索文字片段」命令可设为粘贴或复制。

## 导入和导出

从启动器运行「导入文字片段」或「导出文字片段」。Raycast 兼容 JSON 的字段为 `name`、`text`、`keyword`、`tags`。导出保留占位符原文。富文本样式、图标和置顶状态保存在 Keylane 本地。导入会先显示新增和重复数量，关键词冲突时保留现有片段的关键词。
