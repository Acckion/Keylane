# 计算器对照与本地实现

本次对照以 Keylane `dev` 的 `dbe3e72` 和 Raycast macOS 2.12（2026-11-13）为基线。比较范围为官方手册与 2.12 更新日志明确列出的 macOS 行为。天气、航班、路线及新增行情服务按用户确认留待下一阶段。

| 项目 | 原 Keylane | 本轮实现与边界 |
| --- | --- | --- |
| 主搜索与输入格式 | 双栏结果，回车复制，跟随系统小数点 | 保留入口。新增输入数字分组识别和语法高亮开关。逗号小数地区可用分号分隔函数参数。 |
| 数学表达式 | 四则、乘方、百分号、少量函数、π/e | 增加开方及乘方短语、列表函数、反三角与双曲三角函数、指定小数位及步长舍入、分数和 2–36 进制。裸数字不会触发结果。 |
| 百分比和日常金额 | 可手写算式 | 增加折扣、小费、含税额、加减百分比、拆账、百分比对比及复利。货币符号按系统格式展示。 |
| 单位与组合表达式 | 常用长度、面积、质量、体积、温度、时间、速度 | 增加带量纲的乘除、专用单位、CSS 的 rem/em/像素与打印分辨率换算、时长分解、工作时数、跑步配速、传输耗时、音符频率、物理常数和化学式摩尔质量。摩尔质量使用 CIAAW 的标准值，适用于受支持的元素与括号化学式。 |
| 日期与时间 | 无 | 支持当前及相对日期、ISO 时间戳、周次、期间剩余时长、工作日、日期加减、两时刻及 Unix 时间戳差值。工作日以周一至周五为准。 |
| 时区与地点 | 无 | 识别系统 IANA 时区、代表城市以及常见别名和部分机场代码。显示目的地日期，时钟偏移保留目标时区。已知地点支持离线直线距离。任意地点和地址查询仍待扩展。 |
| 法币与加密货币 | ECB 法币参考汇率、数据日期、离线与过期提示 | 保留现有 ECB 服务。增加法币名称、缩写金额及同币种主辅单位换算，可手动刷新和反转货币对。加密货币实时价格延期。 |
| 文本 | 无 | 可取引号中字符串的前或后若干个字符，按用户可见字符计算。 |
| 颜色 | 剪贴板历史可识别部分 CSS 色值 | 复用基础解析，在主搜索预览 Hex、RGB、HSL、HWB、Lab、LCH 和 Oklab/Oklch，并可复制不同格式和 NSColor。输出到 sRGB 时限制在 sRGB 色域。 |
| 结果操作 | 复制结果 | 增加向上一个应用粘贴、复制无格式结果、复制算式及结果、将答案放回搜索框、交换常规换算单位和显示历史。粘贴使用现有的跨应用权限流程。 |
| 历史 | 无 | 本地记录确认过的结果、离开主搜索和隐藏时的当前结果，保留三个月，最多 1,000 项，支持搜索与复制。 |
| 天气、航班、路线 | 无 | 延期。涉及实时数据、位置访问、卡片和外部服务故障。 |
| 性能 | 本地有界解析及独立 ECB 请求 | 本轮仍用本地有界解析。Raycast 公布的性能数字仅适用于它的版本更新。 |
