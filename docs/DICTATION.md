# 云端听写首版

本轮先实现 macOS 听写工作流，参考 Raycast 的公开手册重新实现交互。仅使用云端语音识别和用户已配置的云端文字模型，不下载本地模型，不新增推理辅助进程或模型闲置释放机制。

## 使用入口

1. 在设置 → AI → 模型与提供方添加或同步语音转写模型，接口与 API Key 统一在 AI 中管理。同一提供方同步出的模型复用已有钥匙串凭据，不复制密钥。然后在设置 → 听写用共用模型选择器选中语音模型；文字整理也直接使用已添加的聊天模型。
2. 开启「启用听写」后才请求麦克风权限。没有开始录音时，不打开麦克风。组合快捷键沿用公共快捷键录制器；也可选择单独修饰键。fn 需要在系统键盘设置中关闭原有动作。单独修饰键和全局完成／取消按键需要辅助功能权限。
3. 选择按一下开始／结束，或按住说话、松开结束。浮条区分麦克风启动、录音、转写和文字整理，支持完成／取消；二十分钟自动结束。
4. 转写后根据全局指令、词汇和应用／网站样式整理。默认使用 AI 命令的模型，也可单独选择；关闭「整理口头表达」后直接使用原始转写。
5. 按输出设置粘贴、复制或粘贴并复制。跨应用粘贴沿用现有授权开关；目标应用、聚焦输入框或光标位置发生变化时，不自动插入，改为保留并复制结果。

## 已接入的工作流

- 「开始听写」「口述提问」「口述创建备忘录」「听写历史」「获取最近听写」「创建听写样式」「添加听写词汇」。
- Quick AI 与 AI Chat 输入框中的麦克风按钮。输入框关闭、切换或离开后取消对应听写，不回写已离开的编辑器。
- 「口述提问」打开 Quick AI 或 AI Chat，将文字追加到共用草稿并保留已有输入，不自动发送。输入框麦克风对当前草稿生效；新建、切换草稿或关闭输入框后，旧听写结果不会写入新草稿。
- 「口述创建备忘录」沿用现有 Apple 备忘录模块，打开预填正文的 Launcher 创建页，由用户确认保存，仍遵循该模块的授权与启用状态。
- 内置邮件／消息样式，可编辑或新增应用与网站规则。网站优先于应用，自定义规则优先于较早的规则；浏览器必须通过辅助功能提供当前页面地址，才能按域名自动匹配。
- 全局指令、最多五十项词汇（每项最多二十字符）、词汇 JSON／文本导入及 JSON 导出。ElevenLabs 不接受的词汇字符或过长短语只参与文字整理，不传给其词汇增强接口；词汇增强的收费以提供方为准。
- 应用上下文默认关闭。开启后，仅将本次聚焦输入框附近文字和应用名称交给整理模型；不截屏，不保存上下文。空格调整在本机完成，不改动转写结果的大小写。
- 自动提交默认关闭；支持每次或结尾词触发，并选择 Return／Shift Return。结尾词从输出中移除，仅在插入后且原输入框仍聚焦时提交；复制、历史重用和重试不会自动提交。
- 麦克风优先列表、提示音、可选录音期间降低系统音量。
- 录制快捷键期间暂停听写触发并取消当前会话，防止修改按键时留下持续录音。播放器暂停／恢复与静音策略暂未接入。
- 本机历史全文搜索、复制、粘贴、查看原始转写、重试／重新整理、逐条删除及清空。统计根据本机成功记录计算，不发送使用遥测。

## 数据与边界

- 直接复用 `AIConfiguration` 的模型目录与钥匙串、`AIModelPicker` 的搜索与键盘交互，以及 `AIRuntime` 的请求会话和取消处理。听写只保存转写／整理模型 ID 与行为设置，不再维护独立的接口、提供方或密钥存储。
- 共享提供方的语音模型与文字模型使用同一个凭据所有者和接口范围；修改主机或接口前缀后不会读取旧目标的密钥。录音上传不跟随重定向，避免把录音或凭据转交其他地址。
- OpenRouter 同步同时读取普通目录和 `models?output_modalities=transcription`，按 `architecture.output_modalities` 识别语音转写模型；旧版仅含聊天模型的缓存会自动补全。转写模型沿用同一提供方的接口和钥匙串密钥，保留现有聊天默认选择。
- 已知 OpenAI Transcribe、Whisper 与 ElevenLabs Scribe 模型自动识别。其他语音模型在 AI 编辑页指定「模型用途」；只有支持相应转写接口的模型才能用于识别，聊天模型用于文字整理。语音模型不进入文字生成的默认选项，也不会替换已有聊天／Quick AI／文件问答默认模型。
- AAC 录音位于应用自己的 `Keylane/Dictation/` 目录。默认成功后删除录音，失败时保留供重试；可显式开启成功录音保留。文本历史包含原始转写、整理结果、时间、应用名称及所选样式。删除记录也删除对应录音，清空还会清理中断留下的录音文件。
- 普通偏好备份不包含听写开关、密钥、历史、词汇或自由文本，导入不会开启录音。
- 每次会话都带独立代次。取消、关闭功能或开始新会话后，旧的捕获、网络和插入回调不得继续投递。删除历史后，迟到的保存也不得恢复已删除记录。
- 转写支持 OpenAI 兼容接口（例如 `gpt-transcribe`）、OpenRouter 与 ElevenLabs Scribe，模型 ID 来自 AI 目录。OpenRouter 使用 `/audio/transcriptions` 的 JSON 格式，发送 m4a 音频的原始字节 Base64、所选模型、语言及词汇提示；自动识别语言时省略语言字段。ElevenLabs 预设也登记在统一提供方列表中；目录同步只接收 Scribe 语音模型，不将语音合成模型加入听写选项。兼容接口的语言、模型和参数支持由其实现决定。
- 本应用不承诺第三方零保留或不训练条款；需遵循用户选择的服务商与账户协议。ElevenLabs 的零保留接口选项有企业账户限制，因此不会替用户默认打开并假称拥有 Raycast 的协议。
- 本轮未实现本地识别、推理进程、麦克风常开预热、团队样式同步、iOS 键盘、AI `@dictation` 工具，也不自动读取其他应用的私有配置。

## 验证

自动检查使用临时目录和合成数据，不读个人录音或真实 API Key，不启用麦克风，不调用付费云端接口。

```sh
swift test --scratch-path .build-current --disable-sandbox --jobs 2
bash scripts/verify-dictation.sh
bash scripts/verify-launcher-modules.sh
python3 -m unittest discover -s Tests/ReleaseTests -p 'test_*.py'
```

Debug 构建支持 `.build-current/debug/Keylane --verify-dictation-ui`，在构造真实 Model 或启动服务前，使用隔离偏好和合成记录渲染个性化、样式编辑与历史页面。图片位于 `/private/tmp/keylane-dictation-ui/`。

本轮已通过 Release 构建的 271 项单元测试（其中 17 项覆盖听写规则、请求及历史），23 项发布脚本测试，以及公共命令／快捷键集成检查和共用 AI 目录、模型筛选、凭据范围与默认模型隔离检查。听写集成检查使用合成 48 kHz 双声道音频，确认同一编码器可生成可读取的 16 kHz 单声道 AAC；云端请求则使用模拟响应检查两类接口、鉴权、取消和失败处理。个性化、样式编辑、历史与共用模型设置的隔离界面均已渲染并复查。

本机 arm64 测试 DMG 已生成，镜像内容、麦克风使用说明、权限声明和 Apple Development 签名均已验证。此包未安装到当前应用，也未发布；签名验证不代表已完成 Apple 公证或 Intel 验收。

连接测试只验证提供方连接（ElevenLabs 使用账户接口），不宣称已验证真实语音识别；实际权限以服务商为准。

真实麦克风授权、蓝牙启动、中英混说质量、真实服务响应、跨应用插入与自动提交仍需在配置用户选择的接口后实机验收；模拟接口通过不代表这些项目已通过。
