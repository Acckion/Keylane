# Navigation 验证记录

- 从主搜索打开「切换窗口」或「搜索菜单项」。两页使用共享搜索框、列表、返回按钮和操作菜单。方向键选择，回车执行，⌘K 可刷新。
- 窗口条目显示应用和窗口标题。优先按本次运行观察到的焦点历史排序，其余按当前可见窗口的层叠顺序排列。焦点历史保存在内存中。
- 菜单条目读取唤起 Keylane 前所在应用的菜单栏，展示路径与快捷键。执行前重新检查可用状态；发现窗口或命令失效时给出反馈。
- 功能需要 macOS 辅助功能权限。两页在未授权时显示授权和重新检查入口。显示范围取决于目标应用通过辅助功能 API 提供的窗口与菜单。

## 已验证

- 38 项 Swift 测试与 6 项版本发布规则测试通过。
- `bash scripts/verify-navigation.sh` 在有权限的测试进程下验证了两个窗口的排序和切换、原生嵌套菜单及快捷键、禁用项未执行、可用命令产生预期结果、目标应用退出后返回错误。
- 同一脚本在权限不足时仅验证快捷键映射与读取取消，输出系统动作未运行。

## Beta 回归

- 切换查询、刷新或重新进入时，过期结果和操作回调不能覆盖当前页。已提交的切换会主动把焦点交给目标应用，因此允许它在启动器随之隐藏后完成。重新加载、模块关闭或撤销权限时取消旧请求。
- 菜单项执行前复核当前角色、标题和启用状态。原生测试使用两个独立测试窗口和只写临时标记的菜单，另外用隔离控制器模拟乱序回调。
- 安装版键盘与授权流程、多屏、全屏和 Spaces 仍待验收。
