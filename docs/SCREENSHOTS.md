# 截图搜索与管理

在主搜索输入「搜索截图」，进入可配置为 3 至 6 列的缩略图网格。图片与录屏可分开筛选，图块下方显示文件创建时间。方向键选择，回车复制到剪贴板，⌘↩ 粘贴到上一个应用。⌘K 打开操作菜单，支持打开、选择打开方式、快速查看、在访达中显示、复制路径、置顶及移到废纸篓。图片还可在「预览」中标注，或复制识别到的文字和二维码内容。左下角菜单提供刷新、添加文件夹、截图设置和分享。

- ⌘+ 放大网格，⌘- 缩小网格，⌘0 恢复默认三列。列数与设置页同步，置顶的截图和录屏在符合当前筛选条件时显示在顶部。
- 文件名和日期可以直接搜索。组合查询示例为 `name:设置 date:2026-11-11`，也支持 `名称:`、`日期:`、`今天`、`昨天`。可用 `date:last week` 或 `日期:上周` 等相对日期，周、月和年按系统日历及本地时区计算。
- 启用文字识别后，用 `text:Keylane` 或 `文字:设置` 查询图片内容。Vision 在本机按需识别图片，缓存保存在内存。录屏可按名称和日期筛选。
- 启用时选择至少一个可访问的目录，可添加多个目录并搜索其子目录。选择器优先建议 macOS 截图保存位置或桌面。目录移走或失去访问权限时，可在设置中重新选择。默认识别系统截图和录屏，打开「包含所有媒体」后会纳入所选范围内的其他图片和视频。
- 截图页打开时会自动刷新目录变化，保留当前筛选和仍匹配的选中项。关闭页面后停止监听，下次打开时重新读取。
- 「粘贴最新截图」会复制最新的图片，并在有辅助功能权限、目标应用仍可用时发送粘贴。
- 设置页支持列数、搜索范围、OCR 模式、云端文件识别开关，以及两个命令的启用状态、别名和热键。云端文件 OCR 默认关闭。
- 网格引用原文件。移到废纸篓前会显示文件名并要求确认，所有原文件默认持续保留。

## 验证

- 34 项 Swift 测试、6 项版本规则测试通过。目录用例覆盖媒体类型、递归、重叠目录去重、隐藏文件与符号链接，以及中英文查询和日期。
- `bash scripts/verify-screenshots.sh` 在 macOS 27.3 用临时生成的 PNG 验证了目录检索、Quick Look 缩略图、Vision OCR、独立剪贴板复制和移到废纸篓。没有使用用户截图作为测试输入。
- 签名的 0.16.0 预览版已实测从主搜索进入截图网格，并从操作菜单打开截图设置。已检查设置页实际布局。
- 跨应用粘贴、选择分享服务、各云盘的下载行为以及不同系统版本待进一步实机验收。

## OCR 缓存与取消回归

使用独立目录生成中英文图片、损坏的 PNG 和 384 个大目录样本，验证按需识别、重复查询、错误提示、切换模式、快速换查询、退出后重开以及移除目录后的处理。替换图片时保留了原路径、文件大小和修改时间，用于验证缓存会区分新的文件身份。OCR 复制失败或取消时，命名测试剪贴板保留原值。

识别默认准确，云端识别默认关闭。实际 iCloud、OneDrive 和 Dropbox 占位文件及系统隐私拒绝待实机验收。本轮只读取合成图片。
